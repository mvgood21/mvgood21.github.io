차서랍 로그인 링크 안내

이 페이지가 보였다면 로그인 링크가 앱이 아니라 브라우저에서 열린 것입니다. 지금 버전의 차서랍은 링크를 눌러 앱으로 돌아가는 기능이 아직 없습니다.

  1. 메일 앱으로 돌아가 로그인 메일을 엽니다.
  2. 로그인 링크를 길게 눌러 링크 주소를 복사합니다.
  3. 차서랍 앱의 로그인 화면에서 메일의 로그인 링크 칸에 붙여 넣고 계속을 누릅니다.

링크는 메일을 받은 이메일 주소로만 쓸 수 있고, 한 번 쓰면 다시 쓸 수 없습니다. 링크가 만료됐다면 앱에서 새 링크를 받으세요. 이 페이지는 주소창의 링크 값을 저장하거나 보내지 않습니다.

Finishing sign-in to CarDrawer

If you see this page, the sign-in link opened in your browser instead of the app. This version of CarDrawer can’t yet return to the app from the link.

  1. Go back to your email app and open the sign-in email.
  2. Long-press the sign-in link and copy the link address.
  3. In CarDrawer’s sign-in screen, paste it into Sign-in link from the email and continue.

The link works only for the email address that received it and only once. If it has expired, request a new link in the app. This page doesn’t store or send the link in the address bar.
