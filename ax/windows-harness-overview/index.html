Claude Code 예약 하네스란: 게임 앱 마케팅

하네스는 Claude Code를 사람 없이 정해진 시각에 돌리고, 결과를 파일로 남기고, 위험한 일은 사람에게 넘기는 틀입니다.

작성 SugarMount · 에이전트와 일하는 법 · 읽는 시간 8분 · 최종 업데이트 2026년 11월 12일

Windows 하네스 연재 1/11 · 다음 편 시작 전 준비: PowerShell 열기

이 연재는 Windows PC 한 대로 게임 앱 마케팅 일을 AI에게 매일 아침 맡기는 방법을 11편에 나눠 씁니다. 1편은 설치 없이 읽으면서, 무엇을 만들게 되는지 보고 내 PC와 계정으로 시작할 수 있는지 판단합니다.

이 편을 마치면

  • 결과: 하네스가 무엇이고 이 연재에서 무엇을 만드는지 압니다. 내 상황에 맞는지 판단할 수 있습니다.
  • 준비물: 없음
  • 비용: 없음. 연재를 따라 하려면 4편(로그인)부터 Claude 유료 요금제가 필요합니다(4단계).

1단계: 하네스가 하는 하루를 본다

하네스(harness)는 AI를 사람 없이 정해진 시각에 돌리고, 결과와 실패를 기록하고, 위험한 행동을 막는 틀 전체를 부르는 말입니다. 이 연재에서는 Anthropic의 Claude를 명령 창에서 쓰는 프로그램인 Claude Code가 그 AI를 맡습니다.

아래 그림에 SugarMount 하네스가 2026-11-10 하루 동안 실제로 돈 시간을 담았습니다.

그림은 이렇게 읽습니다.

  • 9시 11분부터 앱 세 개의 아침 작업(데일리)이 차례로 돕니다. 동시에 돌리지 않고 하나가 끝나면 다음이 시작합니다.
  • 게임 데일리는 10:07에 시작해 13.8분 걸렸습니다. GA4 숫자와 광고, 홍보 영상 소재를 점검하는 작업입니다.
  • 게임 소셜 게시는 20:07에 돌았습니다. 틱톡·인스타그램·유튜브에 영상을 올리는 작업입니다.
  • 맨 아래 세로줄은 15분마다 도는 관리 작업 3종이고, 그날 모두 284회 돌았습니다.

2단계: 대화형 AI와 다른 점을 안다

채팅 창에서 쓰는 AI와 하네스는 일을 시키는 방법이 다릅니다.

질문대화형 AI(채팅 창)하네스
일을 어떻게 시키나창을 열고 질문을 입력합니다할 일을 파일로 미리 써 둡니다
언제 일하나사람이 창 앞에 있을 때시간표에 적은 시각에. 사람이 없어도 됩니다
결과는 어디에화면의 답로그·보고서 파일. 나중에 열어 봅니다
무엇이 있어야 도나열린 대화 창켜진 PC와 로그온한 내 계정

로그온은 Windows에 내 계정으로 들어가 있는 상태를 말합니다. 키트는 비밀번호를 저장하지 않도록 "내가 로그온해 있는 동안만" 돌게 예약합니다. 대화 창에 걸어 둔 예약은 창(세션)을 닫으면 멈추지만, 하네스는 창과 상관없이 Windows가 정한 시각에 실행합니다.

하네스는 Claude Code를 claude -p 방식으로 부릅니다. -p는 대화 창을 열지 않고 질문 하나에 답한 뒤 끝나는 실행 방식(헤드리스 실행)입니다. 4편에서 직접 해 봅니다.

3단계: 키트의 부품 4개를 안다

6편에서 받는 키트는 부품 4개로 움직입니다. 사무실 업무에 빗대면 이렇습니다.

부품비유키트에서하는 일
작업 스케줄러시간표register-job.ps1이 등록Windows에 들어 있는 예약 실행 기능입니다. 예를 들어 매일 09:05에 러너를 실행합니다
작업 카드일 하나를 적은 카드jobs 폴더작업 카드(jobs 폴더의 작업 정의 파일)에는 어떤 지시문을, 어떤 모델로, 어떤 도구만 허용해, 몇 초 안에 끝낼지 적습니다
지시문업무 지시서prompts 폴더Claude에게 시킬 일입니다. 보고 작업은 파일에 있는 숫자만 쓰고, 모든 작업이 마지막에 "판정:" 줄을 씁니다
러너실행 담당run-job.ps1작업 하나를 실행합니다. 겹침을 막고 시간 한도를 걸고, 결과를 업무 일지(logs·reports·state 폴더)에 기록합니다

.ps1은 PowerShell 스크립트, 곧 명령을 모아 둔 파일입니다. 모델은 Claude의 종류를 말합니다. 키트는 동작 확인 작업에 haiku, 나머지 작업에 sonnet을 씁니다.

SugarMount 하네스에는 키트에 없는 부품이 더 있습니다. 이 연재에서는 만들지 않습니다.

실제 하네스에만 있는 부품하는 일
디스패처15분마다 깨어나 앱 데일리를 순서대로 돌리고, 승인된 일을 실행합니다
승인함(결재함)돈·계정·큰 변경처럼 AI가 혼자 하면 안 되는 일을 사람에게 올리는 Notion 표입니다
가드 훅Claude가 도구를 쓰기 직전에 검사해 위험한 명령을 막는 스크립트입니다
감시자모델 없이 상태·로그 파일만 보고 실패와 빠진 회차를 알립니다
데이터 수집 서버매일 09:00에 전날 광고·GA4 숫자를 모아 둡니다(Docker로 돌림)

이 글과 비슷한 문제를 겪고 있다면 메일로 상황을 알려 주세요. 읽고 답하겠습니다. 메일로 문의하기

4단계: 준비물과 비용을 확인한다

연재를 끝까지 따라 하려면 아래가 필요합니다.

  • PC: Windows 11 PC 한 대. Claude Code 문서의 조건은 Windows 10 1809 이상, RAM 4GB 이상, x64 또는 ARM64 프로세서, 인터넷 연결입니다. 내 Windows 판은 2편에서 확인합니다.
  • Claude 요금제: Pro는 월 $20(연간 결제 시 월 $17), Max는 월 $100, Ultra는 월 $200입니다(claude.com/pricing, 2026-11-11 기준). 무료 요금제에는 Claude Code가 없습니다.
  • 켜 둔 PC: 작업 시각에 PC가 켜져 있고 내 계정으로 로그온해 있어야 합니다.
  • 마케팅 계정: GA4(보고서를 내려받으려면 속성의 Viewer 권한), Google Ads, 틱톡·인스타그램·유튜브 채널.
  • Docker Desktop: 선택입니다. 키트는 Docker 없이 돕니다(5편).

이렇게 보이면 성공

네 질문에 모두 "예"라면 2편으로 넘어갑니다. PC가 Windows 10 1809 이상인가, Claude 유료 요금제를 쓸 수 있는가, 아침 작업 시각에 PC를 켜 둘 수 있는가, GA4나 Google Ads 계정에 들어갈 수 있는가.

5단계: 연재 지도를 본다

11편은 아래 묶음 4개로 이루어져 있습니다.

묶음편끝나면 되는 것
설치2~5편PowerShell을 열고, Git과 Claude Code를 설치하고, 로그인해 첫 자동 질문을 보냅니다. Docker는 선택입니다
자동화6~7편키트를 받아 첫 작업을 돌리고, 매일 같은 시각에 돌게 예약합니다
마케팅8~10편GA4 아침 보고, 광고 예산 점검 제안, 틱톡·릴스·쇼츠 영상 계획을 만듭니다
운영11편17일 운영 기록에서 뽑은 시작 순서와 아침 점검 습관을 익힙니다

키트는 광고 계정을 건드리지 않고 제안만 씁니다. 영상도 올리지 않고 계획만 씁니다. 바꾸고 올리는 일은 사람이 합니다.

이 방식이 맞지 않는 경우

이런 경우라면이유이렇게 하세요
PC를 대부분 꺼 두거나 로그온하지 않는다키트 예약은 내가 로그온해 있는 동안만 돕니다. 놓친 회차는 PC가 켜진 뒤 한 번만 돕니다작업 시각에 PC를 켜 두거나, PC를 켜는 시각 뒤로 예약합니다
광고 예산이나 게시를 AI에게 통째로 맡기고 싶다키트는 제안과 계획만 씁니다. 실제 하네스도 돈과 계정이 걸린 일은 사람이 승인합니다제안을 사람이 읽고 바꾸는 방식으로 시작합니다(9편)
무료 Claude 요금제만 쓴다무료 요금제에는 Claude Code가 없습니다Pro 이상 요금제가 필요합니다
32비트 Windows다Claude Code는 32비트 Windows를 지원하지 않습니다64비트 Windows PC를 씁니다
GA4·광고 숫자를 매일 손으로 받기 어렵다키트는 사람이 내려받아 넣은 CSV 파일만 읽습니다자동 수집은 이 연재 범위 밖입니다. 받는 날만 보고서를 돌려도 됩니다

실제 하네스에서는

SugarMount 하네스는 2026-10-25에 시작했습니다. 이전 리눅스 환경에서 돌던 하네스를 멈추고, 코드는 가져오지 않고 교훈만 옮겨 Windows에서 새로 썼습니다.

2026-11-11 기준으로 작업 스케줄러에 등록한 작업은 14개이고, 나머지 작업은 디스패처가 순서대로 부릅니다. 모델은 작업마다 정해 둡니다. 판단이 많은 앱 데일리는 opus, 게시처럼 정해진 화면 조작은 sonnet, 자가 점검은 haiku가 맡습니다.

자주 묻는 질문

Claude 무료 요금제로 하네스를 돌릴 수 있나요?

돌릴 수 없습니다. Claude Code는 Pro, Max, Ultra, Team, Enterprise 또는 Console 계정이 필요하고, 무료 claude.ai 요금제에는 들어 있지 않습니다(2026-11-11 공식 문서).

PC를 꺼 두면 예약은 어떻게 되나요?

그 시각에는 돌지 않습니다. 키트는 놓친 회차를 PC가 켜지고 내가 로그온한 뒤 한 번 돌리도록 예약합니다. 설정은 7편에서 하나씩 설명합니다.

개발 경험이 없어도 따라 할 수 있나요?

이 연재는 명령 창을 처음 여는 사람을 기준으로 씁니다. 2편에서 PowerShell 여는 법과 명령을 붙여 넣는 법부터 다룹니다.

2026-11-12 기준. Claude Code 공식 문서(code.claude.com), claude.com/pricing(2026-11-11 확인), Microsoft 작업 스케줄러 문서, SugarMount 하네스 러너 로그(2026-11-10)와 작업 목록(2026-11-11), 이 연재 키트.
