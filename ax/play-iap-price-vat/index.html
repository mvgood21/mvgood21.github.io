플레이 콘솔 인앱 가격 부가세: 7500원이 8000원

플레이 콘솔 인앱 가격 칸은 부가세를 빼고 넣는 자리라, 7,500원을 넣자 구매자 가격이 8,000원이 됐습니다.

작성 Stephen · 스토어와 수익화 · 읽는 시간 4분 · 최종 업데이트 2026년 11월 19일

콘솔에 7,500원을 넣었는데, 다음 날 앱 설정 화면의 Pro 가격은 8,000원이었습니다. 2026년 10월, 문서 뷰어 한글뷰어 슈가독에 Pro 1회 결제 상품을 등록하는 중이었습니다. AI 코딩 에이전트는 그 칸을 부가세 포함으로 잘못 추정했고, 콘솔 값에 10%가 붙는다는 운영자의 처음 설명이 맞았습니다.

목차 (3)
  1. 6,900원을 보냈는데 7,500원이 저장됐습니다
  2. 가격 환산 API는 세전 값을 받아 세후 값을 냅니다
  3. 문서 가격은 다시 읽은 값으로만 고칩니다

6,900원을 보냈는데 7,500원이 저장됐습니다

10월 5일 클로드 코드(Claude Code) 에이전트는 Play Developer API(콘솔 작업을 코드로 하는 Google API)로 상품을 만들며 운영자가 정한 6,900원을 보냈습니다. 다시 읽은 한국 가격은 7,500원이었습니다. 에이전트는 환산 오류로 보고 6,900원으로 덮어쓰려 했지만, 실제 결제 금액을 바꾸는 작업이라 자동 모드 분류기(사람 승인 없이 위험한 작업을 못 하게 막는 클로드 코드의 검사)가 막았습니다.

운영자는 그 자리에서 콘솔에 6,750원을 넣으면 10%가 붙어 고객은 7,500원에 산다는 취지로 답했습니다. 에이전트는 6,750원에 10%를 더하면 7,425원이라 맞지 않는다며, 저장된 7,500원이 이미 부가세 포함 고객가일 가능성이 크다고 '추정' 표시를 달아 답했습니다. 같은 답에서 6,900원은 10%를 더한 7,590원이 가격대에 맞춰 7,500원이 됐다고 설명하면서, 운영자의 6,750원에는 반올림을 빼고 계산했습니다. 운영자는 콘솔에 7,500원을 넣었고, 에이전트는 운영자 말만 듣고 문서 가격을 고쳤을 뿐 저장값은 다시 읽지 않았습니다.

10월 6일 실기기 E2E(폰에서 앱을 끝까지 눌러 보는 테스트) 보고서에 설정 화면의 8,000원이 찍혔습니다. 가격을 코드에 적지 않고 Play가 주는 값만 보여 주는 앱이라 콘솔 값이 그대로 화면에 나왔습니다.

10월 8일 에이전트는 넣은 값과 저장값 두 쌍을 표로 놓고, 콘솔 가격이 부가세 포함이라고 한 추정이 틀렸다고 정정했습니다. 운영자가 5,000원을 넣자 API가 돌려준 한국 가격은 5,500원이었고, 에이전트가 같은 분에 문서를 고쳤습니다.

가격 환산 API는 세전 값을 받아 세후 값을 냅니다

Google Play 도움말의 세금 문서는 한국을 세금 포함 가격 국가로 두고, 구매자가 보는 가격에 부가세가 들어가야 한다고 적습니다. API 문서의 가격 환산 메서드 convertRegionPrices는 입력을 "Tax exclusive", 나라별 결과를 "tax inclusive"로 적습니다.

문서 가격은 다시 읽은 값으로만 고칩니다

10월 5일 분류기가 막은 뒤로 가격 변경은 운영자가 콘솔에서 하고 에이전트는 읽기만 합니다.

  1. 구매자가 낼 한국 가격을 1.1로 나눠 콘솔에 넣습니다(5,500원이면 5,000원). 딱 떨어지지 않으면 저장값이 가격대에 맞춰 달라질 수 있습니다.

  2. 저장한 뒤 상품 조회 API에서 regionCode KR의 값이나 스토어 화면으로 구매자 가격을 읽습니다.

  3. 문서에는 "구매자 5,500원(콘솔 5,000원)"처럼 두 값을 함께 적습니다.

  4. 가격 환산 API로 상품을 만든다면 입력이 세전 값이라고 코드 주석에 적습니다.

문서의 가격은 저장 뒤 API나 스토어에서 다시 읽은 값으로만 고치십시오. 읽지 않고 넘어간 Play API 결과가 사고가 된 일은 Play 단계적 출시 20%가 100%로 나갔다에도 있습니다.

이 기록은 일회성 상품 하나의 2026년 10월 값입니다. 구독 상품, 한국 사업자로 부가세를 직접 신고하는 계정에서는 확인하지 않았습니다. 콘솔에 넣은 7,500원이 10%를 더한 8,250원보다 낮은 8,000원으로 저장된 것은 관찰값이고, 같은 규칙이 걸린 것인지는 도움말에서 확인하지 못했습니다. 상품을 만드는 스크립트는 한국 가격만 구매자 가격으로 덮고 다른 나라 가격은 같은 값을 세전 가격으로 환산하므로, 다른 나라 가격이 의도보다 높게 잡히는지 다시 돌려 봐야 합니다.

기준일 2026-11-18. 출처: 앱 저장소 git 기록(커밋 2cc25d1, PRD·구현 계획 문서), 에이전트 세션 기록(2026-10-05~10-08), Play Developer API 읽기 전용 조회, Google Play Console 도움말과 Android Publisher API 문서.
