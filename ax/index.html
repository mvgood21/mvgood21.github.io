AX 노트

AX 노트는 SugarMount가 AI 코딩 에이전트와 Android 앱을 만들고 출시하며 정한 규칙과 실제로 측정한 숫자를 남긴 기록입니다.

AX(AI Transformation, AI 전환)를 1인 앱 개발에 적용했습니다. 2026년 9월 20일 첫 커밋부터 20일 동안 Android 앱 4개(사진 용량 줄이기, 사진 반전·회전, 이미지 변환, 한글뷰어 슈가독)를 Google Play에 공개했습니다.

숫자는 모두 SugarMount 앱 저장소의 git 기록, 변경 기록, 실기기 QA 보고서에서 가져왔습니다. 확인하지 못한 것은 확인하지 못했다고 적습니다.

    최신 글

    • Android assets를 미리 gzip한 실측: APK 이득은 0, .pack.gz는 .pack이 되어 FileNotFoundException

      Android assets에 미리 gzip해 넣은 팩 5개는 APK의 deflate보다 18바이트씩 컸고, 이름의 .gz가 빠져 FileNotFoundException까지 났습니다.

      Android 개발 · 측정 · 2026년 10월 31일

    • SKT 판매 삼성 폰에서 market://을 열면 스토어 선택 창이 뜬다: Play 패키지부터 지정하기

      SKT 판매 삼성 폰 두 대에서 market:// 링크를 스토어 앱 3개가 받아 선택 창이 나왔습니다. Play 패키지를 먼저 지정하고 실패할 때만 다음 주소로 넘기자 Play가 바로 열렸습니다.

      Android 개발 · 방법 · 2026년 10월 31일

    • addOnCompleteListener(this)가 onStop에서 지운 리스너 때문에 스플래시에 멈춘 버그

      addOnCompleteListener(this)로 건 Remote Config 리스너가 onStop에서 지워져, 화면이 꺼진 채 실행한 맞춤법 앱이 스플래시에 멈췄습니다. 수정과 기기 시험입니다.

      Android 개발 · 사고 기록 · 2026년 10월 31일

    • 화살표 퍼즐 1,100판을 만든 역구성 생성기와 G2 게이트

      화살표 매듭풀기 1,100판은 역구성 생성기가 만들고 G2 게이트가 걸렀습니다. 이동 규칙을 먼저 고정해 생성이 곧 검증이 됐고, expert F0는 0.50에서 0.11로 내려갔습니다.

      게임 개발 · 방법 · 2026년 10월 30일

    • 대개편 직후 DAU는 올랐고, 자연 유입 코호트 D1은 15.2%에서 11.2%로 내려갔다

      맞춤법 앱의 자연 유입 코호트 D1이 2025년 8월 대개편 뒤 15.2%에서 11.2%로 내려갔습니다. 줄어든 DAU의 70%가 가입 31~365일 층이었고, 원인은 아직 가리지 못했습니다.

      회고와 숫자 · 측정 · 2026년 10월 30일

    • "6.7" < "6.11"이 거짓이라 콘텐츠 갱신이 멈췄다: 6.2~6.9 기기만 막힌 Remote Config 버전 비교

      Kotlin 문자열 비교로 콘텐츠 버전을 견주던 맞춤법 앱이 Remote Config 6.10부터 6.2~6.9에 머문 기기에 문제 은행과 공지를 보내지 못했습니다. 원인과 수정, 확인 절차입니다.

      Android 개발 · 사고 기록 · 2026년 10월 30일

    자주 묻는 질문

    AX가 무엇인가요?

    AX는 AI Transformation(AI 전환)의 줄임말로, 일하는 방식을 AI에 맞게 바꾸는 것을 말합니다. 이 노트에서는 AI 코딩 에이전트에게 코드, 테스트, 출시 스크립트를 맡기고, 사람은 결정과 검증을 맡는 개발 방식을 다룹니다.

    어떤 AI 도구를 쓰나요?

    Anthropic의 Claude Code를 씁니다. 저장소 루트에 둔 지침 파일(AGENTS.md, CLAUDE.md)로 규칙을 전달하고, 큰 작업은 여러 에이전트에게 나눠 맡겨 진행합니다.

    AI가 만든 코드를 그대로 출시하나요?

    아닙니다. 업로드 전에 릴리스 게이트, 축소된 릴리스 빌드 실행 검사, 실기기 E2E를 거칩니다. 자세한 내용은 출시 전 점검 글에 있습니다.

    숫자는 어디서 나왔나요?

    SugarMount 앱 저장소(sugar-utils, 비공개)의 git 기록, CHANGELOG, QA 보고서에서 세어 적었습니다. 각 글에 기준일을 적어 두었습니다.
