앱에 LLM 붙이기: 비용, 캐시, 고지

맞춤법 앱에 Gemini를 붙이며 59건 평가로 1,000건당 $0.93 모델을 고르고, 캐시와 테스트 비용 상한, 처리 위치 고지까지 정한 4편입니다.

4편

이 연재에서 알게 된 것

  • 교정 59건 평가에서 flash-lite는 78%, gemini-3.8-flash는 100%를 맞혔고 비용은 1,000건당 $0.93이었습니다. 서버 함수는 하루 3,000회에서 LLM 호출을 끊고, 출시 뒤 2주 동안 검사 사용자의 3.7%가 '왜 틀렸나요?'를 눌렀습니다. (1편: 비용과 한도)
  • 공유 캐시의 키에 없는 문맥을 모델에 넣으면 한 사람의 프롬프트 인젝션이 모든 사용자의 답이 될 수 있습니다. 조건을 가린 채점에서 문맥 없이 96.6%, 넣고 96.0%라 문맥을 뺐습니다. (2편: 캐시 키와 인젝션)
  • 평가 러너는 2,500원에서 멈추게 돼 있었지만 결제 실측은 2,956원이었습니다(2026-10-11 예산 알림). 장부가 받은 응답만 더했기 때문이고, 그 뒤 상한 값이 없으면 돈을 쓰지 않는 기본값을 둡니다. (3편: 테스트 비용 하드캡)
  • Vertex AI global 엔드포인트는 처리 국가를 하나로 적을 수 없습니다. 방침에 '서울 리전'으로 적은 문장이 8시간 55분 공개됐다가 '한국 밖일 수 있음'으로 바뀌었고, 출시 전이라 실사용자는 없었습니다. (4편: AI 처리 위치 고지)

앱에 LLM 기능을 처음 붙이는 1인 개발자에게 맞는 연재입니다. 1편 모델 고르기, 2편 캐시 설계, 3편 개발 중 비용, 4편 출시 전 고지 순서라 차례로 읽으면 실제 작업 순서와 같습니다. 이미 붙였다면 응답을 캐시하는 경우 2편, 에이전트에게 평가를 돌리게 한다면 3편부터 보십시오. 1편에는 AI Studio 키가 크레딧과 묶이지 않아 평가 59건이 모두 HTTP 402로 거절된 일도 적었습니다.
