에이전트 여럿을 한 저장소에서

동시 실행 수, 서브에이전트 브리프, 파일 주인 표, 커밋 전 게이트, 합친 뒤 리뷰, 반박 리뷰까지 병렬 작업이 부딪힌 자리를 순서대로 봅니다.

연재 목차

  1. 1편'에이전트 수백 개 써도 돼'의 실제: 워크스트림 10개, 하루 59커밋, 동시 실행은 3개

    2026년 10월 21일

    운영자는 에이전트 수백 개를 허락했지만 코드를 쓰는 에이전트는 동시에 3개만 돌았습니다.

  2. 2편서브에이전트 브리프의 절대 규칙 6개와 한도로 끊긴 에이전트 5건

    2026년 11월 2일

    P2P 채팅 앱 출시 준비 중 서브에이전트 5건이 세션·주간 한도로 끊겼습니다.

  3. 3편Claude 세션 여러 개가 한 저장소를 고칠 때: 머지 13개로 확인한 파일 주인 표

    2026년 10월 29일

    같은 작업 트리의 커밋 하나가 다른 세션 파일 50개를 담아 간 뒤 공유 파일 주인 표를 만들었습니다.

  4. 4편여러 에이전트 세션이 고치는 정적 사이트: 커밋 전 --check 게이트 하나

    2026년 10월 25일

    여러 에이전트 세션이 고치는 GitHub Pages 사이트에서 커밋 전 --check로 재빌드 변경 0개와 게이트 오류 0건을 확인합니다.

  5. 5편AI 에이전트 병렬 브랜치 13개를 합친 뒤 통합 리뷰가 확정 결함 12건을 찾았다

    2026년 11월 1일

    리뷰와 CI를 통과한 브랜치 13개를 합친 뒤 통합본만 다시 리뷰하자 확정 결함 12건이 나왔습니다.

  6. 6편에이전트 84개가 돈 릴리스 전 검토: 발견마다 3명이 반박하고, 버틴 20건만 고쳤다

    2026년 10월 22일
