Windows 하네스 연재

Windows PC 한 대에서 Claude Code를 매일 자동으로 돌리는 하네스를, 준비부터 예약 실행과 결과 보고까지 한 편에 한 단계씩 따라 합니다.

11편

연재 목차

  1. 1편Claude Code를 매일 자동으로 돌리는 하네스란

    2026년 11월 11일

    Windows PC 한 대에서 Claude Code가 매일 아침 GA4 보고, 광고 예산 점검, 영상 계획을 써 두게 하는 하네스가 무엇인지, 대화형 AI와 다른 점, 준비물과 요금을 정리했습니다.

  2. 2편PowerShell 처음 열기: 명령 붙여넣기와 경로

    2026년 11월 12일

    명령 창을 처음 여는 분을 위한 준비 편입니다.

  3. 3편Windows에 Git과 Claude Code 설치하기

    2026년 11월 11일

    Git for Windows를 공식 페이지에서 받아 설치하고, PowerShell 명령 한 줄로 Claude Code를 설치한 뒤 claude doctor로 확인합니다.

  4. 4편Claude Code 로그인과 첫 자동 질문 보내기

    2026년 11월 12일

    3편에서 설치한 Claude Code에 브라우저로 로그인하고 claude -p로 첫 자동 질문을 보냅니다.

  5. 5편Windows에 Docker Desktop 설치하기

    2026년 11월 11일

    Windows Pro·Enterprise·Education PC에 WSL과 Docker Desktop을 설치하고 hello-world로 확인합니다.

  6. 6편Claude Code 하네스 키트로 첫 작업 돌리기

    2026년 11월 12일

    연습용 하네스 키트를 내려받아 풀고, 이 PowerShell 창에서만 스크립트 실행을 허용한 뒤 hello 작업을 돌려 로그와 보고서를 읽습니다.

  7. 7편작업 스케줄러로 Claude Code 매일 돌리기

    2026년 11월 11일

    하네스 키트의 register-job.ps1로 hello 작업을 Windows 작업 스케줄러에 매일 9시 5분으로 등록하고, 바로 한 번 돌린 뒤 상태 표로 결과를 확인합니다.

  8. 8편GA4 CSV로 매일 아침 보고서 받기

    2026년 11월 12일

    GA4 보고서를 CSV로 받아 폴더에 넣으면 Claude Code 예약 작업이 아침마다 핵심 숫자 3개와 사람이 확인할 일을 보고서로 남깁니다.

  9. 9편Google Ads 일 예산 점검 보고서 매일 받기

    2026년 11월 12일

    Google Ads 캠페인 표를 CSV로 넣어 두면 Claude Code 예약 작업이 증액·감액 규칙대로 제안을 쓰고, 예산을 바꾸는 결정은 사람이 합니다.

  10. 10편틱톡·릴스·쇼츠 게임 영상 계획을 AI로 매일 받기

    2026년 11월 12일

    키트의 shorts-plan 작업이 게임 소개와 지난 조회수 기록을 읽고 오늘 찍을 숏폼 영상 1편의 제목, 장면 순서, 채널별 문구, 올릴 시각을 씁니다.

  11. 11편Claude Code 하네스 17일 운영과 시작 순서

    2026년 11월 11일

    게임 앱 마케팅 하네스를 17일 돌린 기록에서 실패 7칸, ok가 가린 게시 0건, 로그인 만료 예고를 짚고, 처음 시작할 때 작업을 켜는 순서와 아침 점검법을 정리했습니다.
