스토어와 수익화

Google Play 등록과 심사, 스토어 스크린샷과 설명, 광고 설정처럼 앱을 내놓은 뒤 운영하는 일을 에이전트와 나눠 한 기록입니다.

글 11개

  • 에이전트와 일하는 법
  • 검증과 출시
  • Android 개발
  • 게임 개발
  • 웹사이트와 검색
  • 회고와 숫자

글 목록

  • 구글 앱 캠페인 광고 소재를 플레이 녹화로 만들기

    스토어 스크린샷용 캡처 코드에 화면 녹화와 합성 스크립트를 얹어 Google Ads 앱 캠페인 이미지 24장과 영상 6개를 만들고, 2판은 녹화 없이 사양만 바꿔 22.7초로 다시 잘랐습니다.

  • GA4 CSV로 매일 아침 보고서 받기

    GA4 보고서를 CSV로 받아 폴더에 넣으면 Claude Code 예약 작업이 아침마다 핵심 숫자 3개와 사람이 확인할 일을 보고서로 남깁니다. 받는 법부터 예약까지 다룹니다.

  • Google Ads 일 예산 점검 보고서 매일 받기

    Google Ads 캠페인 표를 CSV로 넣어 두면 Claude Code 예약 작업이 증액·감액 규칙대로 제안을 쓰고, 예산을 바꾸는 결정은 사람이 합니다. 받기부터 기록까지 다룹니다.

  • 틱톡·릴스·쇼츠 게임 영상 계획을 AI로 매일 받기

    키트의 shorts-plan 작업이 게임 소개와 지난 조회수 기록을 읽고 오늘 찍을 숏폼 영상 1편의 제목, 장면 순서, 채널별 문구, 올릴 시각을 씁니다. 촬영과 게시는 사람이 합니다.

  • Claude Code 하네스 17일 운영과 시작 순서

    게임 앱 마케팅 하네스를 17일 돌린 기록에서 실패 7칸, ok가 가린 게시 0건, 로그인 만료 예고를 짚고, 처음 시작할 때 작업을 켜는 순서와 아침 점검법을 정리했습니다.

  • GMA Next-Gen 전면 광고 콜백은 백그라운드 스레드에서 왔다: 사진 앱이 단위 테스트 243개 통과 뒤 죽은 기록

    단위 테스트 243개를 통과한 전면 광고 코드가 에뮬레이터에서 죽었습니다. GMA Next-Gen의 백그라운드 콜백과, 실행마다 false인 UMP canRequestAds()를 적었습니다.

  • Google Ads 앱 캠페인 4개에 $36.4, 설치 105건, ROAS 약 3%: CPI가 손익분기의 30배였다

    퍼즐 게임 Google Ads 캠페인 4개는 10월 17일까지 $36.4로 설치 105건을 얻었고, 가장 나은 한판블록 KR도 ROAS 약 3%, CPI는 손익분기의 약 30배였습니다.

  • 전면 광고 빈도를 기기 타임라인으로 정했다: 안내 퍼즐은 세지 않는다

    새로 깐 S21에서 블록 퍼즐의 첫 전면 광고가 실전 0판 91초에 나왔습니다. 안내 퍼즐을 승수에서 빼 에뮬레이터 첫 전면이 314초로 늦어졌고, 클래식 게임 오버는 두 판으로 세게 했습니다.

  • '한 달째 일시적인 오류'라는 리뷰: 상품을 기다리지 않던 구독 상세 화면, 16명 중 1명만 결제를 시작했다

    Play 리뷰의 '고급 구독 일시적인 오류'는 상품을 기다리지 않는 구독 상세 화면 탓이었습니다. 90일간 16명 중 1명만 결제를 시작했고, 수정 뒤 13명 중 4명이 됐습니다.

  • GA4의 '어제 설치 19건'은 사실 8건이었다: 테스트 기기와 Play 사전 출시·심사 기기 걸러 내기

    GA4에 잡힌 sdk_gphone64_arm64·sdk_gphone16k_arm64는 Play 사전 출시·심사 기기였습니다. 우리 테스트 폰과 함께 설치 수에서 거르는 법입니다.

  • 20% 단계적 출시가 100%로 나갔다: Play Publisher API의 completed는 단계 출시로 되돌릴 수 없다

    한글 띄어쓰기 1.6.029를 Play Publisher API로 20% 단계적 출시하려다 completed(100%)로 커밋했고, 되돌리는 요청은 403이었습니다. 원인과 지금 쓰는 가드입니다.
