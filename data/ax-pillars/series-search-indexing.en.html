What this series found

  • After one commit on October 18, 2026, all 51 URLs in sitemap.xml shared the same lastmod. Once dates came from a hash of each page's main content instead of commit dates, a commit the next day that touched 99 HTML files changed the date on only 6 existing pages. (Part 1: lastmod from a content hash)
  • Behind the "Couldn't fetch" label, the API said isPending=True with no lastDownloaded. A live URL Inspection test on October 25 showed Googlebot fetching the file without trouble, and Bing processed the same sitemap.xml that day. (Part 2: ten days of "Couldn't fetch")
  • After the move to a custom domain on October 31, the same four sitemaps sent to a new domain property were all processed within 7 seconds. During the ten-day wait, indexing grew through URLs we requested one by one; after the move, 5 of 7 requests were indexed within four hours. (Part 2)
  • Google ended FAQ rich results on May 7, 2026 and Naver, Korea's largest search engine, on July 9. 106 of this site's 173 HTML pages carry FAQPage JSON-LD (count of October 27) for zero rich results, and we chose neither to remove nor to extend it. (Part 3: structured data after FAQ results)

This series is for developers running a hand-built static site who are paying attention to search for the first time. If Search Console shows "Couldn't fetch", start with Part 2; if you generate your own sitemap, Part 1; if you are weighing FAQ markup or markup for AI search (GEO), Part 3. All three parts come from a period with almost no impressions, so they report what search engines read and ignored, not ranking gains.
