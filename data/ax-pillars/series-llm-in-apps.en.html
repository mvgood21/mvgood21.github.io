What this series found

  • On 59 corrections, flash-lite explained 78% correctly and gemini-3.8-flash 100%, at $0.93 per 1,000 calls. The server function stops LLM calls at 3,000 a day, and in the two weeks after launch 3.7% of users who ran a check tapped "Why is this wrong?". (Part 1: cost and limits)
  • If the model sees context that the shared cache key leaves out, one user's prompt injection can become everyone's answer. In blind grading, answers without the context scored 96.6% and with it 96.0%, so we dropped it. (Part 2: cache keys and injection)
  • Our eval runner was set to stop at 2,500 KRW, yet billing showed 2,956 KRW (budget alert, October 11, 2026): its ledger only added up calls that returned a response. Now any spending path with no cap set spends nothing. (Part 3: hard caps on test spend)
  • A Vertex AI global endpoint cannot be pinned to one country. A privacy-policy line naming the Seoul region stayed public for 8 hours 55 minutes before it changed to "may be processed outside Korea"; the app had no users yet. (Part 4: disclosing AI location)

This series is for solo developers adding an LLM feature for the first time. The parts follow the real order of work: pick a model (Part 1), design the cache (Part 2), cap spending during development (Part 3), disclose processing before launch (Part 4). If the feature is already live, read Part 2 if you cache responses and Part 3 if an agent runs your evals. Part 1 also covers why all 59 eval calls first failed with HTTP 402: the AI Studio key was not tied to our cloud credit.
