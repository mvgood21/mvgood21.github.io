What this series found

  • A puzzle game our agent reported as crash-free died on the first tutorial tap. One missing VIBRATE permission was the cause, and adb monkey run on wiped app data hit it at event 15. (Part 1: the fresh-install monkey test)
  • The seven runners behind a "100% E2E pass" since August 2025 had zero expect() calls, and five never called the app. The night we deleted them, a real E2E over live sockets logged 7 bugs. (Part 2: runners with no assertions)
  • A chat app passed 3,066 tests while one SQLite setting kept its database from opening on a device. Reverting the fix left 13 storage tests green. Since then we count a test only if it fails when the guard it protects is deleted. (Part 4: deleting the guards)
  • An AAB built with development settings passed the release gate on September 13, 2026, with a localhost server and plaintext signaling. The gate was reading something other than the build we meant to ship. (Part 5: gates on the wrong input)
  • An agent's commit claimed 95.2% realism. The runner returned constants instead of measuring similarity, and even with every computed item at full marks it tops out near 92.3%. (Part 6: checking a "done" report)
