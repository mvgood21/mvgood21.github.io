트림박스 개인정보처리방침

시행일: 2026년 11월 1일 · 방침 버전 0.9.1

이 방침은 simpest(개발자 이름 SugarMount, 이하 “저희”)가 배포하는 Android 캠핑 짐 트렁크 적재 시뮬레이터 트림박스 (TrimBox)(패키지 이름 com.sugarmount.trimbox)에 적용됩니다. 앱이 어떤 데이터를 다루고, 어떤 데이터를 다루지 않는지 앱의 설계와 구현을 기준으로 설명합니다.

1. 요약

이 앱은 이름, 이메일, 전화번호, 정밀 위치, 연락처, 사진을 수집하지 않고, 회원 가입·로그인·결제가 없습니다. 버전 0.9.1부터 Google AdMob 광고(앱 오프닝 광고, 사용자가 고를 때만 재생되는 보상형 광고)를 표시하며, 광고 SDK가 광고 ID와 IP 주소 등을 Google에 보냅니다(2절). 인터넷은 광고 SDK만 쓰고, 짐 배치와 배치 이름은 기기 밖으로 보내지 않습니다. 저희는 서버를 운영하지 않으며, 사용 통계·오류 보고 SDK는 쓰지 않습니다.

2. 인터넷 사용과 광고

인터넷은 광고에만 씁니다

  • 버전 0.9.1부터 앱에 인터넷(INTERNET) 권한이 있습니다. 이 권한은 광고를 불러오고 광고 동의 화면을 표시하는 Google Mobile Ads SDK만 씁니다.
  • 트렁크 모양, 장비 목록, 자동 배치 계산, ‘들어갈까?’ 판정은 모두 앱 안에 들어 있고 기기 안에서 계산합니다. 인터넷이 없어도 앱은 그대로 쓸 수 있고, 그때는 광고만 표시되지 않습니다.
  • 저희는 서버를 운영하지 않습니다. 계정, 로그인, 결제가 없고, 사용 통계(Google Analytics 등)나 오류 보고(Crashlytics 등) 라이브러리도 없습니다.
  • 앱 안의 개인정보처리방침 링크를 누르면 휴대폰의 브라우저가 이 페이지를 엽니다. 이때의 연결은 브라우저가 처리합니다.

광고 형식

앱은 Google AdMob(Google Mobile Ads SDK)으로 광고를 표시합니다. 미디에이션(다른 광고 네트워크 연결)은 쓰지 않습니다. 광고는 다음 두 형식으로만 표시됩니다.

  • 앱을 한동안 다른 화면에 두었다가 다시 돌아올 때 표시될 수 있는 앱 오프닝 광고
  • 사용자가 직접 골랐을 때만 재생되는 보상형 광고(광고를 보고 적재 순서표 카드 이미지 만들기)

광고 콘텐츠는 PG 등급까지로 제한합니다.

광고 SDK가 수집·공유하는 데이터

광고 SDK는 광고를 보여 주고 성과를 측정하며 부정 사용을 막기 위해 다음 정보를 Google의 정책에 따라 자동으로 수집하고, 광고·분석·부정 방지 목적으로 Google과 공유합니다. 전송 중인 데이터는 암호화(TLS)됩니다.

  • 기기 또는 기타 ID: Android 광고 ID, 앱 세트 ID, 그 밖의 기기 식별자
  • 대략적인 위치: IP 주소. 기기의 대략적인 위치(국가·지역 수준)를 추정하는 데 쓰일 수 있습니다. 이 앱은 위치 권한을 요청하지 않으므로 GPS 등 정밀 위치는 광고 SDK에 제공되지 않습니다.
  • 앱 활동(앱 상호작용): 앱 실행, 광고 노출·탭·동영상 시청 같은 상호작용 정보
  • 앱 정보 및 성능(진단 정보): 앱과 광고 SDK의 실행 시간, 멈춤·오류, 성능 정보

이 데이터는 Google이 수집·처리하며 저희가 직접 접근하지 않습니다. 짐 배치, 배치 이름, 장비 목록은 광고 요청에 넣지 않습니다. 정확한 항목과 용도는 Google의 안내를 확인해 주세요.

  • Google 개인정보처리방침
  • Google이 파트너 사이트·앱에서 정보를 사용하는 방법
  • Google Mobile Ads SDK 데이터 수집 공개

동의와 선택 변경

  • 앱은 Google의 User Messaging Platform(UMP)을 사용해, 법적으로 필요한 지역(유럽 경제 지역, 영국, 스위스)에서는 광고를 불러오기 전에 광고 개인정보 동의 화면을 표시합니다. 동의하지 않아도 앱은 그대로 쓸 수 있습니다.
  • 동의가 필요한 지역에서는 앱 정보 화면에 개인정보 옵션이 표시되며, 여기서 언제든지 동의 선택을 바꿀 수 있습니다. 동의가 필요하지 않은 지역에서는 이 메뉴가 표시되지 않습니다.
  • Android 설정의 Google > 광고(또는 개인정보 보호 > 광고) 메뉴에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 광고 ID를 삭제하면 맞춤 광고에 쓰이지 않습니다.
  • 보상형 광고는 사용자가 버튼을 누를 때만 재생됩니다. 누르지 않으면 보상형 광고는 표시되지 않습니다.

3. 기기에 저장되는 데이터

  • 자동 저장: 지금 작업 중인 배치를 저장해 두었다가 앱을 다시 열면 그대로 보여 줍니다.
  • 이름 붙인 배치: 사용자가 이름을 붙여 저장한 배치와 저장 시각, 차종, 짐 개수. 앱의 불러오기 화면에서 하나씩 지울 수 있습니다. 한 배치에는 짐을 64개까지 넣을 수 있습니다.
  • 앱 설정: 화면 언어(시스템·한국어·English), 첫 실행 안내를 봤는지 여부.
  • 광고 기록: 광고가 너무 자주 나오지 않도록 최근 광고를 표시한 시각, 하루 시청 횟수, 앱을 연 횟수를 숫자로만 남깁니다. 광고 동의 상태는 Google UMP가 기기에 저장합니다.
  • 오류 기록: 5절.
  • 이 데이터는 Android의 앱 전용 저장소(SharedPreferences)에 있으며 다른 앱은 읽을 수 없습니다. 앱을 삭제하거나 Android 설정에서 앱 데이터를 지우면 함께 삭제됩니다.

4. 사용자가 누를 때만 기기 밖으로 나가는 것

아래 동작은 모두 사용자가 버튼을 누른 경우에만 일어나고, Android가 제공하는 공유 창·파일 선택기·메일 앱을 거칩니다. 넘겨받은 앱이나 서비스에서의 처리는 그 앱의 정책을 따릅니다.

  • 이미지 공유: 트렁크 화면 이미지(스크린샷)나 적재율·장비 목록을 넣은 공유 카드 이미지를 만들어 Android 공유 창으로 사용자가 고른 앱에 넘깁니다. 이미지와 함께 차종, 적재율, 장비 이름과 치수 목록을 적은 문장도 넘어갑니다. 공유용 임시 파일은 앱 전용 임시 폴더(캐시)에 두고, 다음에 공유하거나 저장할 때 10분이 지난 파일을 지웁니다.
  • 이미지 저장: Android 10 이상에서는 기기의 사진 저장소(Pictures/TrimBox)에 새 이미지 파일로 저장합니다. 저장소 권한을 요청하지 않고, 앱은 사진 저장소의 다른 사진을 읽지 않습니다. Android 7~9에서는 권한을 요청하는 대신 공유 창을 엽니다.
  • 배치 내보내기·가져오기: 배치(차종, 2열 시트 위치, 짐 이름·치수·위치)를 JSON 파일로 저장하거나 불러올 때 Android 시스템 파일 선택기를 씁니다. 어디에 저장하고 어떤 파일을 열지는 사용자가 고르며, 앱은 고른 파일 하나에만 접근합니다. 2MB가 넘는 파일은 열지 않습니다.
  • 피드백 메일: 앱 정보 화면에서 ‘피드백 보내기’를 누르면 휴대폰의 메일 앱이 받는 사람(sugarmount21@gmail.com), 제목(앱 이름·버전, 기기 모델명과 Android API 레벨), 본문의 진단 정보(앱 버전, 기기 모델명과 Android API 레벨, 앱 화면 언어, 지금 화면의 짐 개수)가 채워진 상태로 열립니다. 짐 이름이나 배치 이름은 넣지 않습니다. 오류 기록은 사용자가 ‘오류 기록 첨부’를 켠 경우에만 들어가며(기본은 꺼짐, 5절), 메일은 사용자가 메일 앱에서 보내기를 눌러야 전송됩니다. ‘다음 차종 요청하기’ 메일도 같은 방식으로 받는 사람과 제목, 안내 문장만 채워 엽니다.
  • 메일 앱이 없을 때: 메일 앱을 열 수 없으면 문의 주소를 휴대폰의 클립보드에 복사하고, 사용자가 원하면 메일 제목과 본문도 복사합니다. 클립보드 내용은 기기 밖으로 보내지 않습니다.
  • Google Play 열기: 앱 평가 등을 위해 Google Play 앱(없으면 브라우저)으로 이 앱의 스토어 페이지를 엽니다.

5. 오류 기록

  • 앱에서 오류가 나면 문제를 고치는 데 필요한 기술 정보(오류 종류, 오류 메시지 첫 줄, 코드 위치를 가리키는 스택 상위 줄, 발생 시각(UTC), 같은 오류가 반복된 횟수)를 휴대폰 안의 앱 저장소에 남깁니다. 최근 50건까지만 두고 그보다 오래된 것은 지웁니다.
  • 배치 이름 같은 사용자 입력이 오류 메시지에 섞이지 않도록, 따옴표 안의 글자, 파일 경로·주소·메일 주소 모양의 낱말, 한글 등 영문이 아닌 글자가 든 낱말, 다섯 자리 이상의 숫자는 ‘…’로 가린 뒤 저장합니다.
  • 오류 기록은 자동으로 전송되지 않습니다. 피드백 메일을 쓸 때 사용자가 ‘오류 기록 첨부’를 켠 경우에만 앱 버전, 빌드 종류, 앱 화면 언어와 함께 메일 본문에 들어가며(최대 8,000자), 보내기 전에 메일 앱에서 내용을 보고 지울 수 있습니다.

6. Android 백업

휴대폰에서 Google 백업이 켜져 있으면 Android가 이 앱의 저장 데이터(3절)를 사용자의 Google 계정에 백업하고, 새 기기로 옮길 때 복원할 수 있습니다. 이 백업은 Android와 Google 계정의 기능이며, 저희는 백업된 데이터를 받거나 볼 수 없습니다. 백업은 휴대폰의 설정에서 끌 수 있습니다.

7. 권한

앱은 사용자에게 허용을 요청하는 권한이 없습니다. 아래 권한은 설치할 때 자동으로 주어지며 허용 창이 뜨지 않습니다.

권한용도
인터넷(INTERNET), 네트워크 상태(ACCESS_NETWORK_STATE)광고 SDK가 광고를 불러오고 광고 동의 화면을 표시하는 데 씁니다. 앱의 다른 기능은 인터넷을 쓰지 않습니다.
광고 ID(com.google.android.gms.permission.AD_ID)광고 SDK가 광고 ID를 읽어 광고와 광고 성과 측정에 씁니다. Android 설정에서 광고 ID를 삭제하면 쓰이지 않습니다.
Android 광고 서비스 API(ACCESS_ADSERVICES_AD_ID, ACCESS_ADSERVICES_ATTRIBUTION, ACCESS_ADSERVICES_TOPICS)광고 SDK가 함께 넣는 권한으로, Android의 개인정보 보호형 광고 API(Privacy Sandbox)로 광고와 광고 성과를 측정하는 데 씁니다. 기기의 사진·파일·위치·연락처에는 접근하지 않습니다.
절전 모드 방지(WAKE_LOCK), 포그라운드 서비스(FOREGROUND_SERVICE)광고 SDK가 쓰는 AndroidX WorkManager가 함께 넣는 권한으로, 짧은 백그라운드 작업을 끝까지 마치는 데 씁니다. 알림을 띄우거나 기기의 데이터에 접근하지 않습니다.
com.sugarmount.trimbox.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSIONAndroidX 라이브러리가 앱 안의 신호를 다른 앱이 보내지 못하게 막으려고 자동으로 넣는 권한입니다. 이 앱 자신만 쓰며 기기의 데이터에 접근하지 않습니다.

위치, 연락처, 카메라, 마이크, 사진·미디어·저장소 권한은 선언하지 않습니다. 이미지 저장과 파일 내보내기는 Android 시스템 기능(사진 저장소, 시스템 파일 선택기)을 써서 권한 없이 처리합니다.

8. 제3자 제공, 처리 위탁, 국외 이전

저희는 서버를 운영하지 않으며, 짐 배치와 배치 이름은 이전되지 않습니다. 광고 SDK가 2절의 데이터를 Google에 보내며, Google은 대한민국 밖(미국 등 Google 데이터센터가 있는 국가)에서 이 데이터를 처리·보관할 수 있습니다.

받는 자이전되는 항목목적시기·방법보유 기간
Google LLC (Google AdMob, User Messaging Platform)2절의 광고 ID·앱 세트 ID 등 기기 식별자, IP 주소, 앱·광고 상호작용, 진단 정보, 광고 동의 선택광고 표시와 성과 측정, 분석, 부정 사용 방지, 광고 동의 관리광고를 불러오거나 동의 화면을 표시할 때 암호화된 네트워크(HTTPS)로 전송Google의 정책에 따름

광고 데이터의 이전을 원하지 않으시면 Android 설정에서 광고 ID를 삭제하거나, 앱 사용을 중단하고 삭제해 주세요. 사용자가 공유하거나 메일로 보낸 내용은 사용자가 고른 앱과 서비스가 처리합니다. 저희가 받는 피드백 메일은 Gmail(Google) 메일함에 보관됩니다.

앱에 포함된 구성 요소 중 Flutter, shared_preferences는 기기 안에서만 동작하고, google_mobile_ads(Google Mobile Ads SDK와 UMP)만 위와 같이 Google과 통신합니다. 라이선스 고지는 앱 정보 화면에서 볼 수 있습니다.

앱 설정, 광고 기록, 광고 동의 상태기기 안에만 저장앱 데이터 삭제, 앱 삭제. 광고 동의는 앱 정보 화면의 개인정보 옵션에서 바꿀 수 있습니다(동의가 필요한 지역).
오류 기록기기 안에 최근 50건까지오래된 것부터 자동 삭제. 앱 데이터 삭제, 앱 삭제

사용자가 보낸 피드백·문의 메일문의에 답하고 처리하는 데 필요한 기간 동안 메일함에 보관아래 문의처로 삭제를 요청할 수 있습니다.

보존 기간이 끝나거나 처리 목적이 달성된 데이터는 복구할 수 없는 방법으로 지체 없이 파기합니다.

10. 이용자의 권리

  • 기기에 저장된 배치는 앱에서 직접 지우거나, 앱 데이터 삭제·앱 삭제로 모두 지울 수 있습니다. 저희는 이 데이터를 갖고 있지 않습니다.
  • Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다.
  • 동의가 필요한 지역에서는 앱 정보 화면의 개인정보 옵션에서 광고 동의 선택을 언제든지 다시 할 수 있습니다.
  • 보상형 광고는 보지 않을 수 있습니다. 버튼을 누르지 않으면 재생되지 않습니다.
  • 저희에게 보낸 메일의 열람·정정·삭제·처리정지를 아래 문의처로 요청할 수 있습니다. 광고 데이터처럼 Google이 처리 주체인 데이터는 Google의 절차를 안내해 드립니다.

11. 아동의 개인정보

이 앱은 성인을 대상으로 하며, Google Play의 타겟 연령층은 만 18세 이상입니다. 아동을 대상으로 하지 않으며 연령 정보를 수집하지 않습니다. 만 14세 미만 아동이 보낸 메일이 있다는 사실을 알게 되었거나 법정대리인이 삭제를 요청하시면 아래 문의처로 알려 주세요. 확인 가능한 범위에서 지체 없이 삭제합니다.
