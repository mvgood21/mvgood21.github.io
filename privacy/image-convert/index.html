이미지 변환 JPG·PNG·WebP 개인정보처리방침

시행일: 2026년 10월 22일

이 방침은 simpest(개발자 이름 SugarMount, 이하 “저희”)가 배포하는 Android 앱 이미지 변환 JPG·PNG·WebP – SugarConvert(패키지 이름 com.sugarmount.sugarconvert)에 적용됩니다. 앱이 어떤 데이터를 다루고, 어떤 데이터를 다루지 않는지 실제 구현을 기준으로 설명합니다.

1. 요약

데이터처리 방식처리 주체
사진과 결과 파일기기 안에서만 처리합니다. 업로드하지 않습니다.사용자의 기기
파일 이름·경로·EXIF 등 메타데이터수집하거나 기록하지 않습니다.—
광고 관련 데이터(기기 식별자, 광고 ID 등)Google AdMob 광고 SDK가 Google 정책에 따라 수집할 수 있습니다. 동의 화면(UMP)에서 선택할 수 있습니다.Google
익명 사용 통계기본으로 켜져 있습니다. 설정에서 언제든지 끌 수 있습니다.Google(Firebase / Google Analytics)
오류 보고기본으로 켜져 있습니다. 설정에서 언제든지 끌 수 있습니다.Google(Firebase Crashlytics)
구매 정보Google Play 결제로 처리합니다. 저희는 결제 정보를 받지 않습니다.Google Play
계정 정보계정을 만들지 않으므로 수집하지 않습니다.—

2. 사진과 파일

  • 사진은 Android 사진 선택 도구(Photo Picker)를 통해 사용자가 직접 고른 항목만 앱에 전달됩니다. 앱은 저장소 전체를 읽는 권한을 요청하지 않습니다.
  • 형식 변환, 미리보기, 저장은 모두 사용자의 기기 안에서 이루어집니다. 사진, 결과 파일, 파일 이름은 저희 서버나 제3자에게 전송되지 않습니다. 저희는 별도의 서버를 운영하지 않습니다.
  • 원본 사진은 수정하거나 삭제하지 않습니다. 결과는 사용자가 저장을 선택했을 때 새 파일로 저장됩니다.
  • 파일 이름, 경로, 사진 내용, EXIF 정보는 사용 통계나 오류 보고에 포함하지 않습니다.

3. 광고와 광고 동의

무료 버전은 Google AdMob(Google Mobile Ads SDK)을 사용해 광고를 표시합니다. 광고 SDK는 광고를 보여 주고 부정 사용을 막기 위해 다음과 같은 정보를 Google의 정책에 따라 수집·처리할 수 있습니다.

  • 기기 식별자와 광고 ID(Advertising ID)
  • IP 주소(기기의 대략적인 위치를 추정하는 데 쓰일 수 있습니다)
  • 광고와의 상호작용(노출·클릭 등)과 앱 사용 정보
  • 진단 정보(광고 SDK의 성능·오류 정보)
  • 그 밖에 Google Mobile Ads SDK 데이터 수집 공개 문서에서 안내하는 항목

이 데이터는 Google이 수집·처리하며 저희가 직접 접근하지 않습니다. 정확한 항목과 용도는 Google의 안내를 확인해 주세요.

  • Google 개인정보처리방침
  • Google이 파트너 사이트·앱에서 정보를 사용하는 방법
  • Google Mobile Ads SDK 데이터 수집 공개

동의와 선택 변경

  • 앱은 Google의 User Messaging Platform(UMP)을 사용해, 거주 지역에서 필요한 경우 광고 개인정보 동의 화면을 표시합니다. 동의하지 않아도 앱의 무료 기능은 계속 쓸 수 있습니다.
  • 선택은 앱의 설정 > 광고 개인정보 선택에서 언제든지 바꿀 수 있습니다.
  • Android 설정의 Google > 광고 메뉴에서 광고 ID를 재설정하거나 삭제할 수 있습니다.
  • Pro를 구매하면 광고를 표시하지 않습니다.

4. 사용 통계와 오류 보고

두 항목 모두 기본으로 켜져 있고, 앱의 설정에서 각각 끌 수 있습니다. 사진, 파일 이름, 사진 내용은 어느 쪽에도 포함되지 않습니다. 꺼 둔 동안의 사용 기록은 나중에 다시 켜도 보내지 않습니다.

익명 사용 통계 보내기 (Firebase / Google Analytics)
어느 단계에서 작업이 실패하는지 파악하기 위한 최소한의 익명 앱 사용 이벤트와 기기 정보(모델, OS 버전, 앱 버전 등)를 전송합니다. 사진, 파일 이름, 사진 내용은 포함되지 않습니다.
오류 보고 보내기 (Firebase Crashlytics)
앱이 비정상 종료되거나 오류가 났을 때 기술적인 오류 정보(오류 내용, 기기 모델, OS 버전, 앱 버전 등)를 전송합니다. 사진, 파일 이름, 사진 내용은 포함되지 않습니다.

설정에서 항목을 끄면 그 이후의 수집과 전송이 중단됩니다. 이미 전송된 데이터는 Google의 보존 설정에 따라 처리되며, 앱에서 끄는 것만으로 Google 서버의 기존 데이터가 삭제되지는 않습니다. 삭제를 원하시면 아래 문의처로 알려 주세요.

  • Firebase 개인정보 보호 및 보안
  • Firebase SDK 데이터 수집 공개

5. Pro 구매

  • Pro는 Google Play 결제를 통한 일회성 구매입니다. 결제 수단, 이름, 청구 주소 같은 결제 정보는 Google Play가 처리하며 저희에게 전달되지 않습니다.
  • 앱은 Google Play가 제공하는 구매 상태만 확인해 광고 제거와 처리 장수 한도를 적용합니다.
  • 환불과 결제 내역은 Google Play의 정책과 절차를 따릅니다. Google Play 서비스 약관

6. 계정

이 앱은 계정을 만들거나 로그인을 요구하지 않습니다. 저희가 보관하는 사용자 계정이 없으므로 별도의 계정 삭제 기능도 제공하지 않습니다. 앱이 기기에 저장하는 설정 값은 앱을 삭제하면 함께 삭제됩니다.

7. 보존과 삭제

데이터보존삭제 방법
앱 설정(최근 설정, 저장한 변환 프로필, 실행 이력(날짜·장수·형식·용량만, 파일 이름 없음), 동의 선택, 광고 표시 간격을 지키기 위한 실행 횟수·완료한 작업 수·마지막 광고 시각)기기 안에만 저장되며 어디에도 전송되지 않음앱 삭제 시 함께 삭제됩니다.
변환한 사진(결과 파일)사용자가 저장한 경우 기기의 Pictures/SugarConvert 폴더갤러리나 파일 앱에서 직접 삭제할 수 있습니다.
사용 통계·오류 보고Google(Firebase)의 데이터 보존 설정에 따름설정에서 끄면 이후 전송이 중단됩니다. 기존 데이터 삭제 요청은 문의처로 알려 주세요.
광고 관련 데이터Google의 정책에 따름Android 설정에서 광고 ID를 재설정·삭제할 수 있습니다.

8. 이용자의 권리

사용자는 다음을 요청하거나 직접 설정할 수 있습니다.

  • 사용 통계·오류 보고 전송 여부를 언제든지 앱 설정에서 켜거나 끄기
  • 광고 개인정보 선택을 앱 설정에서 다시 하기
  • Google에 전송된 데이터의 열람·삭제 요청을 아래 문의처로 보내기. 저희는 확인 가능한 범위에서 처리하고, Google이 처리 주체인 데이터는 Google의 절차를 안내해 드립니다.

10. 처리 위탁과 국외 이전

저희는 별도의 자체 서버를 운영하지 않고, 아래 서비스에 데이터 처리를 맡깁니다. 이 서비스는 대한민국 밖(미국 등 Google 데이터센터가 있는 국가)에서 데이터를 처리·보관할 수 있습니다. 사진, 결과 파일, 파일 이름은 이전되지 않습니다.

받는 자이전되는 항목목적시기·방법보유 기간
Google LLC (Google AdMob, User Messaging Platform)3절의 기기 식별자·광고 ID, IP 주소, 광고 상호작용, 진단 정보, 광고 동의 선택광고 표시, 부정 사용 방지, 광고 동의 관리무료 버전에서 광고를 불러올 때 암호화된 네트워크(HTTPS)로 전송. Pro를 구매하면 광고 요청을 하지 않음Google의 정책에 따름
Google LLC (Firebase Analytics)4절의 앱 사용 이벤트, 기기 정보, 앱 인스턴스 ID사용 통계, 작업이 실패하는 단계 파악앱 이용 중 수시로 HTTPS로 전송. 설정에서 끄면 중단Google의 보존 설정에 따름
Google LLC (Firebase Crashlytics)오류 정보, 기기 정보, 앱 버전오류 분석과 수정오류 발생 시 HTTPS로 전송. 설정에서 끄면 중단Google의 보존 설정에 따름

사용 통계와 오류 보고는 설정에서 끄면 이전되지 않습니다. 광고 ID는 Android 설정에서 재설정하거나 삭제할 수 있습니다. Pro 구매는 Google Play가 자체 정책에 따라 처리하며, 저희는 구매 상태만 확인합니다.
