한글 띄어쓰기 (SugarSpeller)

시행일: 2026년 10월 4일

이 방침은 simpest(개발자 이름 SugarMount, 이하 “저희”)가 배포하는 Android 앱 한글 띄어쓰기 (SugarSpeller)(패키지 이름 com.sugarmount.sugarspeller) 버전 1.6.025 이후에 적용됩니다. 앱이 어떤 데이터를 다루고, 어떤 데이터를 다루지 않는지 실제 구현을 기준으로 설명합니다.

1. 요약

이 앱은 이름, 이메일, 전화번호, 위치, 연락처, 사진을 수집하지 않습니다. 다만 맞춤법 검사와 일부 기능을 위해 아래 데이터가 기기 밖으로 전송됩니다.

2. 맞춤법 검사

  • 사용자가 입력하거나, 다른 앱에서 공유하거나, 텍스트 선택 메뉴의 맞춤법 검사로 넘긴 글은 검사를 위해 네이버 맞춤법 검사기 또는 다음(카카오) 맞춤법 검사기로 전송됩니다. 어느 검사기를 쓸지는 앱 설정과 서비스 상태에 따라 정해지며, 한쪽이 실패하면 다른 쪽으로 한 번 다시 보낼 수 있습니다.
  • 이때 각 검사기 서비스는 일반적인 웹 요청처럼 IP 주소와 요청 정보를 받을 수 있고, 검사기 이용에 필요한 쿠키가 앱이 실행되는 동안 메모리에 보관됩니다. 전송된 글의 처리는 네이버·카카오의 개인정보처리방침을 따릅니다.
    • 네이버 개인정보처리방침
    • 카카오 개인정보처리방침
  • 저희는 검사할 글을 저희 서버에 보내거나 저장하지 않습니다. 검사할 글은 사용 통계나 광고 요청에 포함하지 않습니다.
  • 개인정보(주민등록번호, 계좌번호, 비밀번호 등)가 들어 있는 글은 검사하지 않기를 권합니다.

3. “왜 틀렸나요?” AI 설명

  • 교정된 부분을 누르고 왜 틀렸나요?를 선택하면 다음 항목이 저희 서버(Google Firebase Cloud Functions, 서울 리전)로 전송됩니다: 원문 어절과 교정 어절(각각 최대 60자), 오류 유형, 사용한 검사기(네이버·다음), 구독 여부, 앱 버전, 익명 계정 ID(인증 토큰 형태), 앱 무결성 확인 토큰.
  • 서버는 설명을 만들기 위해 어절과 오류 유형만 Google Vertex AI(Gemini)에 보냅니다. Google Cloud 약관에 따라 이 데이터는 Google의 모델 학습에 쓰이지 않습니다. Vertex AI 데이터 거버넌스
  • 교정 구간 앞뒤의 문장이나 글 전체는 전송하지 않습니다.
  • 같은 교정에 같은 설명을 빠르게 주기 위해, 만들어진 설명을 서버(Google Cloud Firestore, 서울 리전)에 보관합니다. 보관 키는 어절 쌍을 되돌릴 수 없게 변환한 값(해시)이며, 누가 요청했는지는 저장하지 않습니다. 설명 문장에는 해당 어절이 들어갈 수 있습니다.
  • 이 기능은 사용자가 버튼을 누를 때만 동작합니다. 쓰지 않으면 위 항목은 전송되지 않습니다.

4. 익명 식별자와 앱 무결성 확인

  • AI 설명의 하루 이용 횟수를 세기 위해 앱을 실행하면 Firebase 익명 계정(이름·이메일·전화번호가 없는 무작위 ID)을 만듭니다. 별도의 회원 가입이나 로그인 화면은 없습니다.
  • 서버는 이 ID별 하루 이용 횟수를 기록하며, 이 기록은 30일이 지나면 자동으로 삭제되도록 설정되어 있습니다. 서버 로그에는 ID를 되돌릴 수 없게 변환한 값(해시)과 요청 결과(오류 유형, 검사기, 앱 버전, 구독 여부, 응답 시간 등)만 남습니다.
  • 앱 데이터를 지우거나 앱을 다시 설치하면 새 ID가 만들어집니다. 이전 ID와 연결되지 않습니다.
  • 정상적으로 설치된 앱의 요청인지 확인하기 위해 Firebase App Check(Google Play Integrity)를 사용합니다. 이 과정에서 Google Play가 기기와 앱의 무결성 정보를 처리할 수 있습니다.

5. 광고

무료로 쓰는 동안 Google AdMob(Google Mobile Ads SDK)을 사용해 배너, 전면, 네이티브, 앱 열기 광고를 표시합니다. AdMob 미디에이션을 통해 Liftoff(Vungle) 광고가 표시될 수도 있습니다. 광고 SDK는 광고를 보여 주고 부정 사용을 막기 위해 다음과 같은 정보를 각사 정책에 따라 수집·처리할 수 있습니다.

  • 기기 식별자와 광고 ID(Advertising ID)
  • IP 주소(기기의 대략적인 위치를 추정하는 데 쓰일 수 있습니다)
  • 광고와의 상호작용(노출·클릭 등)과 앱 사용 정보
  • 진단 정보(광고 SDK의 성능·오류 정보)
  • 그 밖에 Google Mobile Ads SDK 데이터 수집 공개 문서에서 안내하는 항목

이 데이터는 Google과 광고 파트너가 수집·처리하며 저희가 직접 접근하지 않습니다. 검사할 글은 광고 요청에 포함하지 않습니다.

  • Google 개인정보처리방침
  • Google이 파트너 사이트·앱에서 정보를 사용하는 방법
  • Google Mobile Ads SDK 데이터 수집 공개
  • Liftoff 개인정보처리방침

선택 변경

  • Android 설정의 Google > 광고(또는 개인정보 보호 > 광고) 메뉴에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 광고 ID를 삭제하면 맞춤 광고에 쓰이지 않습니다.
  • 구독하면 광고를 표시하지 않습니다.

6. 사용 통계, 원격 설정, 알림

사용 통계 (Firebase / Google Analytics)
앱을 개선하기 위해 앱 사용 이벤트(검사 횟수, 화면 진입, 광고 표시 결과, 구독 화면 이동, 퀴즈 응답 결과 등)와 기기 정보(모델, OS 버전, 앱 버전, 앱 인스턴스 ID, 광고 ID 등)를 전송합니다. 검사할 글과 검사 기록은 포함하지 않습니다. 현재 앱 안에서 사용 통계를 끄는 설정은 제공하지 않습니다. 삭제를 원하시면 아래 문의처로 알려 주세요.
원격 설정 (Firebase Remote Config)
공지, 맞춤법 퀴즈 문제, 사용할 검사기 같은 앱 설정 값을 내려받습니다. 이 과정에서 Firebase 설치 ID와 기기·앱 정보가 Google에 전송될 수 있습니다.
푸시 알림 (Firebase Cloud Messaging)
공지 알림을 보낼 수 있도록 Firebase Cloud Messaging 토큰이 Google에 등록됩니다. 저희는 이 토큰을 별도 서버에 저장하지 않습니다.
아침 퀴즈 알림
맞춤법 퀴즈의 아침 알림은 기기 안의 알람으로 동작하며 서버를 거치지 않습니다. 퀴즈 결과 화면의 스위치나 Android 알림 설정에서 끌 수 있습니다.
  • Firebase 개인정보 보호 및 보안
  • Firebase SDK 데이터 수집 공개

7. 구독과 리뷰

  • 구독은 Google Play 결제를 통한 정기 결제입니다. 결제 수단, 이름, 청구 주소 같은 결제 정보는 Google Play가 처리하며 저희에게 전달되지 않습니다.
  • 앱은 Google Play가 제공하는 구매 상태만 확인해 광고 제거와 AI 설명 이용 한도를 적용합니다. AI 설명 요청에는 구독 여부(예/아니요)만 함께 보냅니다.
  • 구독 해지, 환불, 결제 내역은 Google Play의 정책과 절차를 따릅니다. Google Play 서비스 약관
  • 앱 안에서 Google Play 인앱 리뷰 창을 띄울 수 있습니다. 리뷰 작성은 Google Play에서 처리됩니다.

9. 기기에 저장되는 데이터

  • 검사 기록(원문, 교정문, 오류 정보, 검사 시각)은 기기 안의 앱 전용 저장소에만 저장됩니다. 기록 화면에서 직접 지울 수 있고, 일정 개수를 넘으면 오래된 기록부터 지워집니다.
  • 그 밖에 화면 모드, 퀴즈 진행 상황, 알림 설정, 광고 표시 간격을 위한 횟수, 내려받은 공지·퀴즈 문제가 기기에 저장됩니다.
  • Android의 기기 백업(Google 계정 백업)을 켜 두었다면, 이 데이터가 Android 백업 기능에 따라 사용자의 Google 계정 백업에 포함될 수 있습니다. 저희는 이 백업에 접근할 수 없습니다.

10. 처리 위탁과 국외 이전

저희는 별도의 자체 서버 장비를 운영하지 않고, 아래 서비스에 데이터 처리를 맡깁니다. 이 서비스들은 대한민국 밖(미국 등 Google 데이터센터가 있는 국가)에서 데이터를 처리·보관할 수 있습니다.

받는 자이전되는 항목목적시기·방법보유 기간
Google LLC (Firebase, Google Cloud, Vertex AI)AI 설명 요청 항목, 익명 계정 ID, 앱 무결성 확인 토큰, 서버 로그AI 설명 생성, 이용 횟수 관리, 부정 사용 방지기능 이용 시 암호화된 네트워크(HTTPS)로 전송11. 보존과 삭제 참고
Google LLC (Firebase Analytics, Remote Config, Cloud Messaging)앱 사용 이벤트, 기기 정보, 앱 인스턴스·설치 ID, 광고 ID, 알림 토큰사용 통계, 앱 설정 배포, 알림앱 이용 중 수시로 HTTPS로 전송Google의 보존 설정에 따름

AI 설명 기능을 쓰지 않으면 AI 설명 요청 항목은 이전되지 않습니다. 익명 계정과 사용 통계는 앱 실행 시 자동으로 처리되므로, 이전을 원하지 않으시면 앱 사용을 중단하고 삭제해 주세요. 광고 SDK(Google, Liftoff)와 맞춤법 검사기(네이버, 카카오)는 각사가 자체 정책에 따라 데이터를 처리합니다.

사용자는 다음을 요청하거나 직접 설정할 수 있습니다.

  • AI 설명 기능을 쓰지 않기(버튼을 누르지 않으면 요청 항목은 전송되지 않습니다)
