SugarClip - 모든 복사 공유

시행일: 2026년 10월 4일

이 방침은 simpest(개발자 이름 SugarMount, 이하 “저희”)가 배포하는 Android 앱 SugarClip - 모든 복사 공유(패키지 이름 com.sugarmount.sugarclip)에 적용됩니다. 앱이 어떤 데이터를 다루고, 어떤 데이터를 다루지 않는지 실제 구현을 기준으로 설명합니다.

1. 요약

복사한 내용(클립)과 복사 시각·출처 표시기기 안에만 저장합니다. 앱이 저희 서버나 광고·통계 서비스로 보내지 않습니다(Android 백업은 8번 참고).사용자의 기기

2. 클립보드와 복사한 내용

  • SugarClip은 복사한 내용을 모아 두고 다시 쓰거나 공유하는 앱입니다. 이를 위해 “클립 저장 서비스”가 실행되는 동안 클립보드를 약 1초마다 확인하고, 새로 복사된 텍스트를 클립으로 저장합니다. 서비스는 앱을 열 때와 기기를 다시 켤 때 시작되며, 실행 중에는 상태 알림이 표시되고 알림의 버튼으로 일시정지하거나 끌 수 있습니다. 끈 뒤 앱을 다시 열면 서비스가 다시 시작됩니다. 앱은 알림 권한을 따로 요청하지 않으므로, Android 13 이상에서는 Android 설정에서 SugarClip 알림을 허용해야 상태 알림과 버튼이 보일 수 있습니다.
  • Android 10 이상에서는 Android가 백그라운드 앱의 클립보드 읽기를 막기 때문에, 보통 SugarClip 화면이 열려 있을 때 복사된 내용만 저장됩니다. Android 9 이하에서는 앱이 백그라운드에 있어도 복사가 일어나면 저장될 수 있습니다.
  • 클립마다 저장하는 항목은 복사된 텍스트(웹문서 형식이 있으면 그 형식 포함), 복사한 시각, 클립보드에 붙은 출처 표시(라벨), 내용 형식(텍스트·웹문서·웹주소 등)입니다. 이 정보는 기기 안의 앱 전용 저장소에만 보관되며, 저희 서버나 광고·통계 서비스로 전송하지 않습니다. 저희는 이 앱을 위한 별도의 서버를 운영하지 않습니다.
  • 새 클립이 저장되면 앱은 사용자가 “클립 저장” 설정에서 고른 앱(기본값은 카카오톡이며, Google Keep, OneNote, Evernote 중에서 고를 수 있음)의 공유 화면을 엽니다. 클립 상세 화면에서도 공유 버튼으로 다른 앱에 보낼 수 있습니다. 공유는 Android 공유 기능을 통해 이루어지며, 실제로 보낼지와 받는 사람은 사용자가 그 앱에서 정합니다. 이후의 처리는 사용자가 고른 앱의 정책을 따릅니다.
  • 복사한 내용에는 비밀번호, 인증번호, 계좌번호 같은 민감한 정보가 들어 있을 수 있습니다. 이런 내용을 복사할 때는 알림에서 서비스를 일시정지하거나 끄고, 저장된 클립은 앱에서 삭제해 주세요. 저희는 클립 내용을 볼 수 없습니다.
  • 앱은 카카오 로그인 등 외부 계정 연동을 사용하지 않습니다. 공유 대상 목록은 저희가 Firebase Remote Config로 내려보내는 공유 대상 앱의 패키지 이름 목록이며, 기기에 설치된 앱 목록을 수집하거나 전송하지 않습니다.

3. 권한

클립보드 읽기 자체에는 Android 권한이 필요하지 않습니다. 앱이 선언한 권한과 용도는 다음과 같습니다.

권한용도
포그라운드 서비스, 절전 해제(FOREGROUND_SERVICE, WAKE_LOCK)클립 저장 서비스가 실행되는 동안 클립보드 확인이 멈추지 않도록 사용합니다.
부팅 완료 알림 받기(RECEIVE_BOOT_COMPLETED)기기를 다시 켠 뒤 클립 저장 서비스를 다시 시작하기 위해 사용합니다.
알림(POST_NOTIFICATIONS)Firebase Cloud Messaging 라이브러리가 추가하는 권한으로, 클립 저장 서비스의 상태 알림과 앱 공지 알림을 표시하는 데 쓰입니다. 앱이 실행 중에 이 권한을 요청하지 않으므로, Android 13 이상에서는 Android 설정에서 직접 허용해야 알림이 표시될 수 있습니다. 허용하지 않아도 앱을 쓸 수 있습니다.
인터넷, 네트워크 상태(INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE)광고 표시, 사용 통계, 앱 설정(버전·공지 정보, 공유 대상 앱 목록) 조회, 푸시 알림에 사용합니다. 클립 내용 전송에는 쓰지 않습니다.
광고 ID 등(com.google.android.gms.permission.AD_ID, ACCESS_ADSERVICES_AD_ID·ATTRIBUTION·TOPICS)Google AdMob과 Google Analytics가 광고 ID와 Android 개인정보 보호 샌드박스 광고 API를 사용하는 데 쓰입니다(아래 4·5번 참고).
설치 경로 확인(BIND_GET_INSTALL_REFERRER_SERVICE)Google Analytics가 앱이 어떤 경로로 설치되었는지 확인하는 데 쓰입니다.
그 밖의 선언(SYSTEM_ALERT_WINDOW, READ_LOGS, GET_CLIPS, READ_CLIPS, WRITE_CLIPS)이전 버전에서 이어진 선언입니다. 현재 버전은 다른 앱 위에 표시 권한을 요청하지 않으며, 시스템 로그(READ_LOGS)는 일반 앱에 허용되지 않는 권한이라 읽지 않습니다. 개인정보를 수집하는 데 쓰지 않습니다.

위치, 연락처, 카메라, 마이크, 저장소(사진·파일), 통화 기록 권한은 요청하지 않습니다. 접근성 서비스도 사용하지 않습니다.

4. 광고

앱은 Google AdMob(Google Mobile Ads SDK)을 사용해 배너 광고를 표시합니다. 광고 SDK는 광고를 보여 주고 부정 사용을 막기 위해 다음과 같은 정보를 Google의 정책에 따라 수집·처리할 수 있습니다. 클립 내용은 광고 SDK에 전달하지 않습니다.

  • 기기 식별자와 광고 ID(Advertising ID)
  • IP 주소(기기의 대략적인 위치를 추정하는 데 쓰일 수 있습니다)
  • 광고와의 상호작용(노출·클릭 등)과 앱 사용 정보
  • 진단 정보(광고 SDK의 성능·오류 정보)
  • 그 밖에 Google Mobile Ads SDK 데이터 수집 공개 문서에서 안내하는 항목

이 데이터는 Google이 수집·처리하며 저희가 직접 접근하지 않습니다. 정확한 항목과 용도는 Google의 안내를 확인해 주세요.

  • Google 개인정보처리방침
  • Google이 파트너 사이트·앱에서 정보를 사용하는 방법
  • Google Mobile Ads SDK 데이터 수집 공개

광고 개인정보 선택

  • 현재 버전에는 앱 안의 별도 광고 동의 화면이나 광고 설정 메뉴가 없습니다.
  • Android 설정의 Google > 광고 메뉴에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 광고 ID를 삭제하면 맞춤 광고에 쓰이지 않습니다.
  • Google 계정의 내 광고 센터에서 맞춤 광고를 끌 수 있습니다.

5. 사용 통계, 앱 설정, 푸시 알림 (Firebase)

앱은 Google의 Firebase 서비스를 사용합니다. 복사한 내용(클립)은 어느 서비스에도 포함되지 않습니다.

사용 통계 (Firebase / Google Analytics)
앱 실행, 화면 이용 같은 자동 수집 이벤트와 기기 정보(모델, OS 버전, 앱 버전, 언어, 대략적인 국가·지역 등), 앱 인스턴스 ID, 광고 ID, 설치 경로를 Google에 전송합니다. 서비스 개선과 이용 현황 파악에 씁니다. 현재 버전에는 앱 안에서 이 수집을 끄는 설정이 없습니다.
앱 설정 조회 (Firebase Remote Config)
앱을 시작할 때 최신 버전 정보, 공지·자주 묻는 질문 내용, 공유 대상 앱 목록을 받아 옵니다. 이 과정에서 Firebase 설치 ID와 앱 버전 등 기술 정보가 Google에 전달됩니다. 받아 온 내용은 기기 안에 저장됩니다.
푸시 알림 (Firebase Cloud Messaging)
공지 알림을 보낼 수 있도록 기기마다 알림 토큰이 만들어져 Google에 등록됩니다. 저희는 이 토큰을 별도 서버에 모으지 않습니다. Android 설정에서 앱 알림을 허용하지 않거나 끄면 알림이 표시되지 않습니다.
  • Firebase 개인정보 보호 및 보안
  • Firebase SDK 데이터 수집 공개

6. 계정과 결제

이 앱은 계정을 만들거나 로그인을 요구하지 않습니다. 저희가 보관하는 사용자 계정이 없으므로 별도의 계정 삭제 기능도 제공하지 않습니다. 앱 안 결제 기능도 없습니다.

7. 처리 위탁과 국외 이전

저희는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 광고 표시와 앱 운영을 위해 아래 서비스를 이용하며, 이 과정에서 일부 정보가 국외로 전송됩니다. 복사한 내용(클립)은 이전 항목에 포함되지 않습니다.

이전받는 자이전 국가이전 항목이전 일시·방법목적보유·이용 기간
Google LLC (개인정보 문의)미국 등 Google이 데이터 센터를 운영하는 국가광고 ID 등 기기 식별자, IP 주소, 광고 상호작용, 앱 사용 이벤트, 기기 정보, 설치 경로, Firebase 설치 ID, 알림 토큰앱을 사용하는 동안 네트워크를 통해 수시로 전송광고 표시, 사용 통계, 앱 설정 조회, 푸시 알림Google의 정책과 Firebase 데이터 보존 설정에 따름

국외 이전을 원하지 않으시면 앱을 삭제해 주세요. 광고와 통계 기능은 앱 운영에 포함되어 있어 앱 안에서 따로 끌 수 없습니다.

8. 보존과 파기

데이터보존삭제 방법
저장된 클립(복사한 텍스트, 복사 시각, 출처 표시, 내용 형식)사용자가 삭제할 때까지 기기 안의 앱 전용 저장소에만 저장됩니다. 기기의 Android 백업 기능이 켜져 있으면 사용자의 Google 계정 백업에 포함될 수 있습니다.앱에서 클립을 하나씩 삭제하거나, Android 설정에서 앱 데이터를 삭제하거나, 앱을 삭제하면 지워집니다.
앱 설정(공유 대상 앱 선택, 화면 설정), 받아 온 공지·버전 정보와 공유 대상 앱 목록기기 안의 앱 전용 저장소에만 저장되며 저희나 광고·통계 서비스로 전송되지 않습니다. Android 백업이 켜져 있으면 사용자의 Google 계정 백업에 포함될 수 있습니다.Android 설정에서 앱 데이터를 삭제하거나 앱을 삭제하면 함께 삭제됩니다.
다른 앱으로 공유한 클립사용자가 고른 앱의 정책에 따름해당 앱에서 직접 삭제해 주세요.
사용 통계, 앱 설정 조회 기록, 알림 토큰Google(Firebase)의 데이터 보존 설정에 따름앱을 삭제하면 이후 전송이 중단됩니다. 기존 데이터 삭제 요청은 문의처로 알려 주세요.
광고 관련 데이터Google의 정책에 따름Android 설정에서 광고 ID를 재설정·삭제할 수 있습니다.

저희가 직접 보관하는 개인정보는 없습니다. 기기 안의 데이터는 앱 데이터를 삭제하거나 앱을 삭제할 때 함께 지워집니다. Google 계정 백업에 남은 사본은 Google 계정의 백업 관리에서 삭제할 수 있습니다.

9. 이용자의 권리

사용자(만 14세 미만 아동은 법정대리인)는 다음을 요청하거나 직접 할 수 있습니다.

  • 저장된 클립을 앱에서 확인하고 삭제하기
  • 알림의 버튼으로 클립 저장 서비스를 일시정지하거나 끄기
  • 공유 대상 앱을 “클립 저장” 설정에서 바꾸기
  • 알림 허용 여부를 Android 설정에서 언제든지 바꾸기
  • Android 설정에서 광고 ID를 재설정하거나 삭제하기
  • Google에 전송된 데이터의 열람·정정·삭제·처리 정지 요청을 아래 문의처로 보내기. 저희는 확인 가능한 범위에서 지체 없이 처리하고, Google이 처리 주체인 데이터는 Google의 절차를 안내해 드립니다.
