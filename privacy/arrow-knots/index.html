화살표 매듭풀기 (Arrow Knots)

시행일: 2026년 10월 3일

이 방침은 simpest(개발자 이름 SugarMount, 이하 “저희”)가 배포하는 Android 게임 화살표 매듭풀기 - Arrow Knots(패키지 이름 com.sugarmount.arrows) 버전 1.0.0에 적용됩니다. 앱이 어떤 데이터를 다루고, 어떤 데이터를 다루지 않는지 실제 구현을 기준으로 설명합니다.

1. 요약

이 게임은 어떤 개인정보도 수집하거나 공유하지 않습니다. 광고, 사용 통계(분석), 오류 보고, 계정이 없고, 인터넷 권한도 요청하지 않습니다.

데이터처리 방식처리 주체
게임 진행 기록(레벨, 최고 기록·점수, 설정)기기 안의 앱 전용 저장소에만 저장합니다. 전송하지 않습니다.사용자의 기기
광고 관련 데이터(기기 식별자, 광고 ID 등)광고가 없으므로 수집하지 않습니다.—
사용 통계·오류 보고분석 도구와 오류 보고 도구를 쓰지 않으므로 수집하지 않습니다.—
계정 정보계정을 만들지 않으므로 수집하지 않습니다.—
그 밖의 개인정보(위치, 연락처, 사진 등)접근하지 않으며 수집하지 않습니다.—

2. 권한과 인터넷 연결

  • 앱이 요청하는 Android 권한은 진동(VIBRATE) 하나뿐입니다. 화살표가 막혔을 때 등 게임 중 진동 피드백에 쓰이며, 설정에서 끌 수 있습니다.
  • 앱에는 인터넷 권한(INTERNET)이 없습니다. 따라서 앱은 저희 서버나 제3자에게 어떤 데이터도 보낼 수 없습니다. 저희는 별도의 서버를 운영하지 않습니다.
  • 위치, 연락처, 카메라, 사진·저장소, 마이크 같은 권한은 요청하지 않습니다.

3. 광고·분석·제3자 서비스

이 버전에는 광고 SDK, 분석 SDK, 오류 보고 SDK, 결제 기능이 들어 있지 않습니다. 데이터를 제3자에게 제공하거나 공유하지 않습니다.

4. 계정

이 게임은 계정을 만들거나 로그인을 요구하지 않습니다. 저희가 보관하는 사용자 계정이 없으므로 별도의 계정 삭제 기능도 제공하지 않습니다.

5. 보존과 삭제

데이터보존삭제 방법
게임 진행 기록(도달한 레벨, 레벨별 최고 기록·점수·별, 튜토리얼 완료 여부)과 설정(소리·진동·타이머·콤보 표시)기기 안의 앱 전용 저장소에만 저장되며 어디에도 전송되지 않음Android 설정에서 앱 데이터를 삭제하거나 앱을 삭제하면 함께 삭제됩니다.

저희는 이 데이터에 접근할 수 없으므로, 기기 밖에서 열람하거나 삭제해 드릴 데이터도 없습니다.

6. 아동의 개인정보

이 게임은 만 13세 미만 아동을 주요 대상으로 하지 않습니다. 앱은 연령과 관계없이 어떤 이용자의 개인정보도 수집하지 않습니다.

7. 방침 변경

앱의 데이터 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다. 이후 버전에서 광고나 사용 통계 같은 기능을 추가하게 되면, 해당 버전을 배포하기 전에 이 방침을 먼저 갱신해 어떤 데이터가 어떻게 처리되는지 안내합니다.
