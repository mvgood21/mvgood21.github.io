쉬운 동영상 만들기 - 슈가앨범 (SugarAlbum)

시행일: 2026년 10월 4일

이 방침은 simpest(개발자 이름 SugarMount, 이하 “저희”)가 배포하는 Android 앱 쉬운 동영상 만들기 - 슈가앨범(패키지 이름 com.sugarmount.sugaralbum)에 적용됩니다. 앱이 어떤 데이터를 다루고, 어떤 데이터를 다루지 않는지 실제 구현을 기준으로 설명합니다.

2. 사진·동영상과 동영상 만들기

  • 앱은 사용자가 동영상에 넣을 사진과 동영상을 고를 수 있도록 기기의 사진·동영상 목록을 읽습니다. 이를 위해 사진·동영상 접근 권한을 요청합니다(아래 3번 참고). Android 14 이상에서는 일부 사진만 허용할 수도 있습니다.
  • 장면 고르기, 효과·테마 적용, 배경 음악 합성, 동영상 인코딩과 미리보기는 모두 사용자의 기기 안에서 이루어집니다. 사진, 동영상, 만든 동영상, 파일 이름은 저희 서버나 제3자에게 전송되지 않습니다. 저희는 이 앱을 위한 별도의 서버를 운영하지 않습니다.
  • 더 자연스러운 장면을 만들기 위해 앱은 고른 사진의 촬영 날짜, 방향, 해상도 같은 정보와 화질을 기기 안에서 분석합니다. 이를 지원하는 일부 기기에서는 사진 속 얼굴의 위치(눈·입 위치 등)를 감지해 확대·구도 조정에 쓸 수 있습니다. 이 분석 결과는 기기 안에만 보관되며, 특정인을 식별하거나 외부로 전송하는 데 쓰지 않습니다.
  • 배경 음악은 앱에 포함된 음원을 사용합니다. 앱은 마이크나 카메라 권한을 요청하지 않으며, 녹음하거나 촬영하지 않습니다.
  • 원본 사진과 동영상은 수정하거나 삭제하지 않습니다. 만든 동영상은 새 파일로 기기의 Movies/SugarAlbum 폴더에 저장됩니다.
  • 사용자가 공유 버튼을 누르면 Android 공유 화면을 통해 사용자가 고른 앱으로 동영상이 전달됩니다. 이후의 처리는 사용자가 고른 앱의 정책을 따릅니다.

3. 권한

권한용도
사진·동영상 접근(READ_MEDIA_IMAGES, READ_MEDIA_VIDEO, READ_MEDIA_VISUAL_USER_SELECTED / Android 12L 이하는 READ_EXTERNAL_STORAGE)동영상에 넣을 사진과 동영상을 고르고 읽기 위해 사용합니다.
저장소 쓰기(WRITE_EXTERNAL_STORAGE)동영상 엔진 라이브러리가 선언한 권한으로, Android 10 이하 기기에서 만든 동영상을 기기 저장소에 저장할 때 쓰입니다.
알림(POST_NOTIFICATIONS)동영상 만들기·저장 진행 상황과 앱 공지 알림을 표시하기 위해 사용합니다. 거부해도 앱을 쓸 수 있습니다.
포그라운드 서비스(FOREGROUND_SERVICE 및 미디어 처리·데이터 동기화·짧은 서비스 유형), 절전 해제(WAKE_LOCK)화면을 벗어나도 동영상 만들기와 저장이 중간에 멈추지 않도록 사용합니다.
인터넷, 네트워크 상태(INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE)광고 표시, 사용 통계, 앱 설정(공지·버전 정보) 조회, 푸시 알림에 사용합니다. 사진과 동영상 전송에는 쓰지 않습니다.
광고 ID(com.google.android.gms.permission.AD_ID)Google AdMob과 Google Analytics가 광고 ID를 읽는 데 사용합니다(아래 4·5번 참고).
Android 광고 개인정보 보호 API(ACCESS_ADSERVICES_AD_ID, ACCESS_ADSERVICES_ATTRIBUTION, ACCESS_ADSERVICES_TOPICS)Google Mobile Ads SDK가 자동으로 선언하는 권한입니다. 이 기능을 지원하는 기기에서 광고 관심 주제(Topics)와 광고 성과 측정(Attribution)에 쓰일 수 있습니다(아래 4번 참고).
Google Play 서비스 연동(com.google.android.c2dm.permission.RECEIVE, BIND_GET_INSTALL_REFERRER_SERVICE)Firebase SDK가 자동으로 선언하는 권한으로, 푸시 알림 수신과 Google Analytics의 설치 경로(install referrer) 확인에 쓰입니다.
그 밖의 시스템 권한(DISABLE_KEYGUARD, BROADCAST_STICKY, SYSTEM_ALERT_WINDOW, MEDIA_CONTENT_CONTROL)이전 동영상 엔진에서 이어진 선언으로, 개인정보를 수집하는 데 쓰지 않습니다.

위치, 연락처, 카메라, 마이크, 통화 기록 권한은 요청하지 않습니다.

4. 광고

앱은 Google AdMob(Google Mobile Ads SDK)을 사용해 배너, 전면, 네이티브, 앱 시작 광고를 표시합니다. 광고 SDK는 광고를 보여 주고 부정 사용을 막기 위해 다음과 같은 정보를 Google의 정책에 따라 수집·처리할 수 있습니다.

  • 기기 식별자와 광고 ID(Advertising ID)
  • IP 주소(기기의 대략적인 위치를 추정하는 데 쓰일 수 있습니다)
  • 광고와의 상호작용(노출·클릭 등)과 앱 사용 정보
  • 진단 정보(광고 SDK의 성능·오류 정보)
  • Android 광고 개인정보 보호 API를 지원하는 기기에서는 관심 주제(Topics)와 광고 성과 측정(Attribution) 신호
  • 그 밖에 Google Mobile Ads SDK 데이터 수집 공개 문서에서 안내하는 항목

이 데이터는 Google이 수집·처리하며 저희가 직접 접근하지 않습니다. 정확한 항목과 용도는 Google의 안내를 확인해 주세요.

  • Google 개인정보처리방침
  • Google이 파트너 사이트·앱에서 정보를 사용하는 방법
  • Google Mobile Ads SDK 데이터 수집 공개

광고 개인정보 선택

  • 현재 버전에는 앱 안의 별도 광고 동의 화면이나 광고 설정 메뉴가 없습니다.
  • Android 설정의 Google > 광고 메뉴에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 광고 ID를 삭제하면 맞춤 광고에 쓰이지 않습니다.
  • Google 계정의 내 광고 센터에서 맞춤 광고를 끌 수 있습니다.

5. 사용 통계, 앱 설정, 푸시 알림 (Firebase)

앱은 Google의 Firebase 서비스를 사용합니다. 사진, 동영상, 파일 이름, 사진 분석 결과는 어느 서비스에도 포함되지 않습니다.

사용 통계 (Firebase / Google Analytics)
앱 실행, 화면 이용 같은 자동 수집 이벤트와 기기 정보(모델, OS 버전, 앱 버전, 언어, 대략적인 국가·지역 등), 앱 설치 경로(install referrer), 앱 인스턴스 ID, 광고 ID를 Google에 전송합니다. 서비스 개선과 이용 현황 파악에 씁니다. 현재 버전에는 앱 안에서 이 수집을 끄는 설정이 없습니다.
앱 설정 조회 (Firebase Remote Config)
앱을 시작할 때 최신 버전 정보와 공지·자주 묻는 질문 내용을 받아 옵니다. 이 과정에서 Firebase 설치 ID와 앱 버전 등 기술 정보가 Google에 전달됩니다. 받아 온 공지 내용은 기기 안에 저장됩니다.
푸시 알림 (Firebase Cloud Messaging)
공지 알림을 보낼 수 있도록 기기마다 알림 토큰이 만들어져 Google에 등록됩니다. 저희는 이 토큰을 별도 서버에 모으지 않습니다. 알림 권한을 거부하거나 Android 설정에서 앱 알림을 끄면 알림이 표시되지 않습니다.
  • Firebase 개인정보 보호 및 보안
  • Firebase SDK 데이터 수집 공개

6. 계정과 결제

이 앱은 계정을 만들거나 로그인을 요구하지 않습니다. 저희가 보관하는 사용자 계정이 없으므로 별도의 계정 삭제 기능도 제공하지 않습니다. 앱 안 결제 기능도 없습니다.

7. 처리 위탁과 국외 이전

저희는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 광고 표시와 앱 운영을 위해 아래 서비스를 이용하며, 이 과정에서 일부 정보가 국외로 전송됩니다.

이전받는 자이전 국가이전 항목이전 일시·방법목적보유·이용 기간
Google LLC (개인정보 문의)미국 등 Google이 데이터 센터를 운영하는 국가광고 ID 등 기기 식별자, IP 주소, 광고 상호작용, 앱 사용 이벤트, 기기 정보, Firebase 설치 ID, 알림 토큰앱을 사용하는 동안 네트워크를 통해 수시로 전송광고 표시, 사용 통계, 앱 설정 조회, 푸시 알림Google의 정책과 Firebase 데이터 보존 설정에 따름

국외 이전을 원하지 않으시면 앱을 삭제해 주세요. 광고와 통계 기능은 앱 운영에 포함되어 있어 앱 안에서 따로 끌 수 없습니다.

8. 보존과 파기

데이터보존삭제 방법
사진 분석 결과, 동영상 구성 정보, 받아 온 공지 내용, 앱 설정기기 안에만 저장됩니다. 기기의 Android 백업 기능이 켜져 있으면 사용자의 Google 계정 백업에 포함될 수 있습니다.Android 설정에서 앱 데이터를 삭제하거나 앱을 삭제하면 함께 삭제됩니다.
만든 동영상기기의 Movies/SugarAlbum 폴더갤러리나 파일 앱에서 직접 삭제할 수 있습니다.
사용 통계, 앱 설정 조회 기록, 알림 토큰Google(Firebase)의 데이터 보존 설정에 따름앱을 삭제하면 이후 전송이 중단됩니다. 기존 데이터 삭제 요청은 문의처로 알려 주세요.
광고 관련 데이터Google의 정책에 따름Android 설정에서 광고 ID를 재설정·삭제할 수 있습니다.

저희가 직접 보관하는 개인정보는 없습니다. 기기 안의 앱 데이터는 앱을 삭제하면 Android가 함께 삭제합니다.

9. 이용자의 권리

사용자(만 14세 미만 아동은 법정대리인)는 다음을 요청하거나 직접 할 수 있습니다.

  • 사진·동영상, 알림 권한을 Android 설정에서 언제든지 회수하기
  • Android 설정에서 광고 ID를 재설정하거나 삭제하기
  • Google에 전송된 데이터의 열람·정정·삭제·처리 정지 요청을 아래 문의처로 보내기. 저희는 확인 가능한 범위에서 지체 없이 처리하고, Google이 처리 주체인 데이터는 Google의 절차를 안내해 드립니다.
