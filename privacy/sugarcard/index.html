생생카드 (SugarCard)

시행일: 2026년 10월 4일

이 방침은 simpest(개발자 이름 SugarMount, 이하 “저희”)가 배포하는 Android 앱 생생카드: 인사말 카드 – SugarCard(패키지 이름 com.sugarmount.sugarcard)에 적용됩니다. 앱이 어떤 데이터를 다루고, 어떤 데이터를 다루지 않는지 실제 구현을 기준으로 설명합니다.

저희는 별도의 서버를 운영하지 않으며, 이름·연락처·주소 같은 개인정보를 직접 수집하지 않습니다.

2. 카드 문구와 이미지

  • 카드 이미지, 글꼴, 배경 음악은 앱에 포함되어 있습니다. 카드에 문구를 얹고 이미지나 동영상(MP4)으로 만드는 작업은 모두 사용자의 기기 안에서 이루어집니다.
  • 사용자가 입력한 문구, 완성한 카드 이미지·동영상은 저희 서버나 광고·분석 서비스로 전송되지 않습니다.
  • 카드를 공유하면 이미지·동영상을 앱의 임시 저장 공간(캐시)에 만든 뒤, 사용자가 고른 앱(예: 메신저)으로 넘깁니다. 이후의 처리는 사용자가 선택한 앱의 정책을 따릅니다.
  • 공유 버튼을 누르면 작성한 문구와 작성 시각, 글자 수 같은 간단한 통계를 기기 안의 기록(히스토리)에 저장합니다. 기록 화면에서 항목별로 삭제할 수 있고, 앱을 삭제하면 함께 삭제됩니다.
  • 다른 앱에서 텍스트를 생생카드로 공유하면, 그 텍스트를 카드 문구 입력란에 채워 넣는 데만 사용합니다.
  • 앱은 사진첩, 연락처, 위치, 카메라, 마이크에 접근하지 않습니다.

3. 광고

앱은 Google AdMob(Google Mobile Ads SDK)을 사용해 배너 광고, 앱 실행 시 광고, 종료·기록 화면의 네이티브 광고를 표시합니다. 광고 SDK는 광고를 보여 주고 부정 사용을 막기 위해 다음과 같은 정보를 Google의 정책에 따라 수집·처리할 수 있습니다.

  • 기기 식별자와 광고 ID(Advertising ID)
  • IP 주소(기기의 대략적인 위치를 추정하는 데 쓰일 수 있습니다)
  • 광고와의 상호작용(노출·클릭 등)과 앱 사용 정보
  • 진단 정보(광고 SDK의 성능·오류 정보)
  • 그 밖에 Google Mobile Ads SDK 데이터 수집 공개 문서에서 안내하는 항목

이 데이터는 Google이 수집·처리하며 저희가 직접 접근하지 않습니다. 정확한 항목과 용도는 Google의 안내를 확인해 주세요.

  • Google 개인정보처리방침
  • Google이 파트너 사이트·앱에서 정보를 사용하는 방법
  • Google Mobile Ads SDK 데이터 수집 공개

광고 선택 변경

  • 현재 버전은 앱 안에서 별도의 광고 동의 화면이나 광고 설정 메뉴를 제공하지 않습니다.
  • Android 설정의 Google > 광고 메뉴에서 광고 ID를 재설정하거나 삭제할 수 있습니다. 광고 ID를 삭제하면 맞춤 광고에 광고 ID가 쓰이지 않습니다.
  • Android 13 이상에서는 설정 > 보안 및 개인정보 보호 > 광고 개인정보 보호 메뉴에서 광고 관련 기능을 조정할 수 있습니다(기기마다 메뉴 이름이 다를 수 있습니다).
  • 구독하면 광고가 줄어듭니다. 베이직 구독은 앱 실행 시 광고와 팝업 광고를 표시하지 않고, 프리미엄 구독은 배너 광고도 표시하지 않습니다. 다만 현재 버전은 앱 종료 화면의 광고를 구독 여부와 관계없이 표시합니다.

4. 사용 통계, 앱 설정 조회, 알림

앱에는 Google Firebase SDK가 포함되어 있습니다. 문구, 카드 이미지·동영상은 어느 기능에도 포함되지 않습니다.

사용 통계 (Firebase / Google Analytics)
앱 실행, 화면 이용 같은 자동 수집 이벤트와 기기 정보(모델, OS 버전, 앱 버전, 언어·국가 설정 등), 앱 인스턴스 ID, 광고 ID를 Google로 전송할 수 있습니다. 앱을 어떻게 쓰는지 파악하고 개선하는 데 사용합니다. 현재 버전은 앱 안에서 이 기능을 끄는 설정을 제공하지 않습니다.
앱 설정 조회 (Firebase Remote Config)
앱을 시작할 때 공지사항, FAQ, 점검·업데이트 안내를 받아 옵니다. 이 과정에서 Firebase 설치 ID와 앱 버전 같은 기술 정보가 Google로 전송됩니다.
푸시 알림 (Firebase Cloud Messaging)
알림을 보낼 수 있도록 Firebase가 기기별 알림 토큰을 만듭니다. 저희는 이 토큰을 별도로 수집하거나 다른 정보와 연결하지 않습니다. Android 13 이상에서는 사용자가 알림을 허용한 경우에만 알림이 표시되며, Android 설정에서 언제든지 알림을 끌 수 있습니다.
  • Firebase 개인정보 보호 및 보안
  • Firebase SDK 데이터 수집 공개

5. 그 밖의 인터넷 연결

앱의 메인 화면은 예전 맞춤법 기능과 공유하는 코드 때문에 화면이 열릴 때 네이버 검색 페이지(search.naver.com)에 접속해 웹 페이지를 받아 올 수 있습니다. 이 요청에는 사용자가 입력한 문구나 카드 내용이 포함되지 않습니다. 다만 일반적인 웹 접속과 마찬가지로 IP 주소와 기기·접속 정보(User-Agent 등)가 네이버에 전달될 수 있고, 네이버가 설정한 쿠키를 앱이 실행되는 동안 보관했다가 다시 보낼 수 있으며, 이는 네이버 개인정보처리방침에 따라 처리됩니다.

6. 구독 결제

  • 광고 줄이기 등 혜택을 위한 구독은 Google Play 결제로 처리합니다. 결제 수단, 이름, 청구 주소 같은 결제 정보는 Google Play가 처리하며 저희에게 전달되지 않습니다.
  • 앱은 Google Play가 제공하는 구독 상태만 확인해 광고 표시 여부와 혜택을 정합니다. 구독 메뉴는 버전에 따라 표시되지 않을 수 있습니다.
  • 구독 해지, 환불, 결제 내역은 Google Play의 정책과 절차를 따릅니다. Google Play 서비스 약관

8. 계정

이 앱은 계정을 만들거나 로그인을 요구하지 않습니다. 저희가 보관하는 사용자 계정이 없으므로 별도의 계정 삭제 기능도 제공하지 않습니다. 앱이 기기에 저장하는 데이터는 앱을 삭제하면 함께 삭제됩니다.

11. 이용자의 권리

사용자는 다음을 요청하거나 직접 설정할 수 있습니다.

  • 앱의 기록 화면에서 저장된 문구 기록을 삭제하기
  • Android 설정에서 광고 ID를 재설정·삭제하고, 알림을 켜거나 끄기
  • Google에 전송된 데이터의 열람·삭제·처리 정지 요청을 아래 문의처로 보내기. 저희는 확인 가능한 범위에서 지체 없이 처리하고, Google이 처리 주체인 데이터는 Google의 절차를 안내해 드립니다.
