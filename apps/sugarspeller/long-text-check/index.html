맞춤법 검사기 글자 수 제한, 휴대폰으로 긴 글 검사

웹 맞춤법 검사기는 한 번에 300~1,000자까지만 받아요. 휴대폰에서는 한글 띄어쓰기 앱으로 무료 3,000자, 구독하면 7,000자까지 한 번에 검사해요.

작성 SugarMount · 읽는 시간 6분 · 최종 업데이트 2026년 10월 18일

이 글은 SugarMount가 만든 Android 앱 '한글 띄어쓰기'(SugarSpeller) 1.6.031 소스를 기준으로 써요. 글자 수 제한이 아예 없는 방법은 아니에요. 7,000자가 넘는 글은 나눠서 검사해야 해요.

앱 없이 하는 방법과 한계

가장 흔한 방법은 포털의 웹 맞춤법 검사기예요. 2026년 10월 18일에 확인했을 때 네이버 검색 결과의 맞춤법 검사기 입력 칸에는 0/300자, 다음 맞춤법 검사기 페이지에는 0/1000자 표시가 있었어요. 글자 수는 공백도 함께 세요.

  • 긴 글은 여러 번 나눠 붙여 넣어야 해요. 2,000자 자기소개서라면 300자 검사기에서는 7번, 1,000자 검사기에서는 2번에 나눠야 해요. 문단 중간에서 끊으면 앞뒤 문맥이 잘려 띄어쓰기 판단이 달라질 수 있어요.
  • 고친 결과를 다시 이어 붙여야 해요. 나눠서 검사했으면 교정문을 순서대로 모아 붙이는 일도 직접 해야 해요.
  • PC에서는 편하지만 휴대폰에서는 번거로워요. 작은 화면에서 긴 글을 선택하고 나누는 일이 가장 손이 많이 가요.

띄어쓰기를 직접 점검할 때는 한글 맞춤법의 기본 원칙을 기억해 두면 좋아요. 국립국어원 한글 맞춤법 제1장 총칙은 이렇게 정하고 있어요.

"문장의 각 단어는 띄어 씀을 원칙으로 한다."

출처: 국립국어원 한국어 어문 규범, 한글 맞춤법 제1장 제2항

한글 띄어쓰기 앱으로 긴 글 검사하기

  1. 글 넣기 — 앱 아래쪽 입력 칸에 글을 붙여 넣거나, 메모·카카오톡 같은 다른 앱의 공유 메뉴에서 한글 띄어쓰기를 골라요. 공유로 받은 글은 바로 검사하지 않고 입력 칸에 먼저 들어가요.
  2. 글자 수 확인 — 입력하는 동안 '1234/3000'처럼 지금 글자 수와 한도가 보여요. 한도를 넘는 뒷부분은 입력 칸에 들어가지 않으니, 숫자가 한도와 같다면 글이 잘린 거예요. 남은 부분은 따로 검사하세요.
  3. 검사 보내기 — 보내기 버튼을 누르면 앱이 글을 300자 안팎의 조각으로 나눠 검사하고, 결과를 한 글로 다시 합쳐 보여 줘요. 조각은 공백·마침표·줄바꿈 자리에서 끊어요.
  4. 고친 부분 확인 — 밑줄 친 부분을 누르면 원문과 교정이 나란히 나와요. 왜 틀렸나요?를 누르면 틀린 이유를 AI가 짧게 설명해 줘요.
  5. 복사하거나 공유하기 — 결과 아래 복사·공유 버튼으로 교정문을 원래 쓰던 곳에 옮겨요.

화면: Galaxy S21 실기기, 한글 띄어쓰기 1.6.025, 2026년 10월 1일 캡처(위쪽 상태 표시줄은 잘라 냈어요). 글자 수 한도와 조각 크기는 1.6.031 소스에서 확인했어요. 메뉴 모양은 버전에 따라 조금 다를 수 있어요.

한 번에 검사하는 글자 수 비교

방법한 번에2,000자 글이라면비용이럴 때 쓰세요
웹 검사기(검색 결과 화면)300자7번 나눠 검사무료한두 문장만 빠르게 볼 때
웹 검사기(사전 페이지)1,000자2번 나눠 검사무료PC에서 중간 길이 글을 볼 때
한글 띄어쓰기 무료3,000자한 번에무료(광고 있음)휴대폰에서 자기소개서 한 문항을 통째로 볼 때
한글 띄어쓰기 기본 구독4,000자한 번에유료(배너 광고 있음)3,000자를 조금 넘는 글을 자주 볼 때
한글 띄어쓰기 고급 구독7,000자한 번에유료(광고 없음)여러 문항을 한꺼번에 볼 때

판정: 3,000자 이하 글을 휴대폰에서 검사한다면 앱 무료판으로 충분해요. 그보다 길면 문항별로 나눠 무료로 검사하거나, 자주 쓴다면 구독을 고르세요. 한두 문장이라면 앱을 깔 필요 없이 웹 검사기로 충분해요.

안 될 때와 한계

  • 글자 수 제한이 없는 건 아니에요. 무료 3,000자, 기본 4,000자, 고급 7,000자예요. 공백과 줄바꿈도 한 글자로 세요.
  • 인터넷이 필요해요. 앱이 직접 맞춤법을 판단하지 않고, 글을 네이버 또는 다음(카카오) 맞춤법 검사기로 보내 결과를 받아 와요. 어느 쪽을 쓸지는 앱 설정 서버가 정하고, 한쪽이 실패하면 다른 쪽으로 한 번 더 시도해요.
  • 오래 걸리면 실패로 알려요. 30초 안에 모든 조각의 결과가 오지 않으면 검사를 멈추고 다시 시도하라고 알려 줘요.
  • 공유로 넘긴 글은 줄바꿈이 사라져요. 공유 메뉴로 받은 글은 연속된 공백과 줄바꿈을 공백 하나로 합쳐요. 문단 구분이 중요하면 입력 칸에 직접 붙여 넣으세요.
  • 글자를 선택해 고르는 메뉴는 짧은 글용이에요. 다른 앱에서 글자를 길게 눌러 맞춤법 검사를 고르면 300자까지는 작은 창에서 바로 검사하고, 그보다 긴 글은 앱 본화면으로 넘겨요.
  • 검사기가 고치는 범위까지만 고쳐요. 문장이 어색한지, 내용이 맞는지는 봐 주지 않아요. 제출 전에는 한 번 소리 내 읽어 보세요.

글은 어디로 가나요

검사할 글은 검사를 위해 네이버 또는 다음(카카오) 맞춤법 검사기로 보내요. 왜 틀렸나요?를 누를 때만 그 부분의 원래 어절과 고친 어절, 오류 종류가 SugarMount 서버(Google Firebase)를 거쳐 Google Vertex AI로 가요. 앞뒤 문장은 보내지 않아요. 자기소개서처럼 개인 정보가 들어간 글이라면 이 점을 알고 쓰세요. 자세한 내용은 한글 띄어쓰기 개인정보처리방침에 있어요.

글자를 선택해 고르는 메뉴는 Android가 앱에 텍스트 처리를 맡기는 표준 기능이에요. Android 개발자 문서는 이렇게 설명해요.

"Activity Action: Process a piece of text."

선택한 글 한 토막을 앱이 처리하도록 넘기는 동작이라는 뜻이에요. 출처: Android Developers, Intent.ACTION_PROCESS_TEXT

자주 묻는 질문

글자 수 제한이 없는 맞춤법 검사기가 있나요?

한글 띄어쓰기도 제한이 있어요. 무료 3,000자, 기본 구독 4,000자, 고급 구독 7,000자예요. 그보다 긴 글은 문단이나 문항 단위로 나눠 검사하세요.

공백도 글자 수에 들어가나요?

네. 앱의 글자 수 표시와 한도는 공백과 줄바꿈을 포함해 세요. 자기소개서의 '공백 제외' 글자 수와는 다를 수 있어요.

3,000자를 넘게 붙여 넣으면 어떻게 되나요?

한도를 넘는 뒷부분은 입력 칸에 들어가지 않아요. 글자 수 표시가 '3000/3000'이라면 잘린 것이니, 남은 부분을 따로 붙여 넣어 검사하세요.

검사한 글이 저장되나요?

검사한 원문과 교정문은 휴대폰 안의 검사 기록에 남아요. 기록을 남기고 싶지 않으면 '검사 기록 남기기' 설정을 끄면 돼요. 끈 뒤에 검사한 글은 기록되지 않아요.

계정을 만들어야 하나요?

아니요. 회원가입 없이 써요. 다만 검사는 인터넷이 연결돼 있어야 해요.
