Adding an LLM to an app

Model choice and call limits, prompt injection in a shared cache, a hard cap on test spend and disclosing where AI processing happens.

4 parts

Series contents

  1. Part 1The first LLM feature in a spell-check app: cost, model evaluation and daily caps for "Why is this wrong?"

    November 4, 2026

    A 59-case eval picked a Gemini model at $0.93 per 1,000 calls, a 3,000-call daily cap in the function limits spend, and an AI Studio 402 moved us to Vertex AI.

  2. Part 2A shared LLM cache could have frozen a prompt injection: the blind A/B that let us stop sending context

    October 27, 2026

    A shared LLM cache keyed without the context could serve one injected answer to every user.

  3. Part 3Capping Vertex AI test costs: a 2,500 KRW stop line missed a 2,956 KRW bill, so we changed the defaults

    November 11, 2026

    Our evaluation runner stopped at 2,500 KRW, yet billing showed 2,956 KRW: its ledger counted only responses.

  4. Part 4Privacy policy AI processing location (cross-border transfer): a notice fixed twice in one day, then tied to code

    October 23, 2026

    A Vertex AI global endpoint cannot be named as one country, so our privacy policy says processing may happen outside Korea, tied to code and CI.
