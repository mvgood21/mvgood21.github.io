Building the SugarDoc HWP viewer

One document viewer from design review to rendering engine, incoming files, PDF, edit-and-save, Hancom compatibility and malicious-file tests, in the order it was built.

    October 27, 2026

    Before coding a document viewer, 3 agent designs competed and 3 judges scored them.
