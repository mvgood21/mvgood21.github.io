Windows harness series

Set up a harness that runs Claude Code every day on one Windows PC, one step per part, from installing the tools to scheduled runs and reports.

11 parts

Series contents

  1. Part 1What a Claude Code harness is, for game marketing

    November 11, 2026

    A harness runs Claude Code on a Windows PC at fixed times each day. How it differs from a chat AI, what you need, what it costs, and the 11-part plan.

  2. Part 2Open PowerShell and paste your first command

    November 12, 2026

    For readers who have never used a command window: check your Windows version, open the right PowerShell, paste a command and read your user folder path.

  3. Part 3Install Git and Claude Code on Windows

    November 11, 2026

    Download Git for Windows from its official page and install it, then install Claude Code with one PowerShell line and confirm it with claude doctor.

  4. Part 4Claude Code login and a first unattended question

    November 12, 2026

    Sign in to Claude Code from Windows PowerShell, ask a first question with claude -p, give scheduled jobs their own sign-in, and see when a sign-in ends.

  5. Part 5Install Docker Desktop on Windows with WSL 2

    November 11, 2026

    Install WSL and Docker Desktop on Windows Pro, Enterprise or Education and test it with hello-world.

  6. Part 6Run a first Claude Code harness job with the kit

    November 12, 2026

    Download the practice harness kit, unzip it, allow scripts in one PowerShell window only, then run the hello job and read the log, report and state file.

  7. Part 7Run Claude Code every day with Task Scheduler

    November 11, 2026

    Use the kit's register-job.ps1 to schedule the hello job in Windows Task Scheduler for 09:05 daily, start it once now, and check the result in the status table.

  8. Part 8GA4 CSV export to a daily morning report

    November 12, 2026

    Download a GA4 report as CSV, drop it in a folder, and a scheduled Claude Code job writes a morning report with three key numbers and what you should check.

  9. Part 9A daily Google Ads budget check that only suggests

    November 12, 2026

    Export your Google Ads campaign table as CSV and a scheduled Claude Code job suggests budget raises and cuts by fixed rules.

  10. Part 10TikTok, Reels and Shorts plans with Claude Code

    November 12, 2026

    The kit's shorts-plan job reads your game notes and past view counts, then writes today's video plan: shot list, captions and posting times.

  11. Part 1117 days of a Claude Code harness: how to start

    November 11, 2026

    From 17 days of a game-marketing harness: 7 failed cells out of 51, an "ok" that hid zero posts, a sign-in expiry warning, and which job to switch on first.
